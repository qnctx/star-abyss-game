# 原生角色与御空控制（首个可玩切片）

`scripts/native_player.gd` 挂在 `CharacterBody3D`。节点原点位于脚底；子节点为 `CollisionShape3D`、`Model` 和 `CameraPivot/Camera3D`。`NativeMain` 在生成地形后调用 `set_world(world)` 和 `set_support_provider(camp)`，从而让画面、物理碰撞、脚底高度和御空边界共用真实场景数据。

## 操作与规则

| 按键 | 地面 | 空中 |
| --- | --- | --- |
| WASD | 移动 | W/S 沿镜头俯仰方向前后飞，A/D 水平侧移 |
| Space | 跳跃 | 不起飞、不二段跳 |
| G | 灵息至少 25% 时按住起飞；不足时保持按住可在回息后自动起飞 | 按住上升 |
| C | 无 | 下降，接近地面时着陆；Shift+C 加快下降 |
| Shift | 地面冲刺 | 有三维移动输入且灵息不少于 10 时加速 |
| Ctrl | 精细步行，限速 1.6 米/秒 | 精细飞行，限速 5 米/秒（Shift 加速优先） |
| V | 切换第一/第三人称 | 同左 |
| 鼠标 | 转向/抬头 | 同左 |
| 右键 | 格挡，受伤降至 25% | 同左 |
| R | 当前境界拳掌／横扫／下劈武技 | 同左，使用空中动作片段 |

按 Escape 释放鼠标，左键重新捕获。捕获鼠标的第一次点击被消费，不会误触战斗。悬停时身体直立；有实际切向速度的普通巡航持续前倾，Shift 加速进一步前倾，下降、上升和受击／施法恢复按当帧径向速度与输入平滑选姿。按住 Shift+A/D 时有持续且平滑的侧倾，镜头保持水平。左键攻击由 `NativeMain` 控制。

R3 武技由 `NativeMain` 以实际物理帧驱动：R4 右拳、R5 左掌、R6/R7 横扫、R8 下劈、R9 压掌。动作、灵息、独立冷却、手部骨点、准星目标、释放与命中事件由 [战斗契约](r3-combat-contract.md) 统一；受击、瞬移和上车取消尚未释放的招式，已释放的短行程效果可继续命中。`NativePlayer.receive_combat_hit(event)` 处理敌方伤害与格挡，普通格挡承受 25%，破防会解除格挡并进入硬直。R 与 Space 的输入分离，Space 不会触发武技。

元婴（R4）近地限速为 48 米/秒；随离地高度平滑提高，在 350 米以上巡航上限 420、加速上限 600 米/秒。转向每秒不超过 1.8 弧度，起步加速度分别为 165/300 米/秒²，放开方向键后以 420 米/秒²减速。飞行时镜头俯仰参与 W/S 方向，G/C 的垂直输入与 WASD 合成后再归一化，斜向输入不会叠加超速；纯 G/C 及俯仰带来的升降仍受高度相关的升降限速和逐帧加减速约束。Shift 可加快纯 C 下降。向下看但没有按 C 时，会按剩余离地高度提前制动并停在约 0.42 米飞行净空；只有 C 或灵息耗尽会主动触发着陆。落地时把残余空中水平速度限制到地面冲刺速度，避免高速御空速度延续成滑步。

离地上限 2,000 米，灵息耗尽时下降，地面以每秒 4.0 恢复；普通御空缓慢耗能、Shift 加速明显耗能。21% 灵息在地面约一秒恢复到 25% 起飞线。HUD 显示低能回息倒计时、加速限制及耗尽降落，并在低空显示一位小数，避免把 0.42 米悬停误读为已落地。R5–R9 的巡航/加速上限按网页规则表保留。每个物理帧飞行前分段检查地形、6 公里盆地边界和世界体积，再交给 Godot 的 `move_and_slide()` 处理实际碰撞。

实际脚底碰到地面时会清除残留的御空状态；降到营地真实地板上也一样，随后可以再次按 G 起飞。第三人称镜头从肩部向后做半径 0.24 米的物理扫掠，在营地墙体、地形和裂翼兽的镜头专用碰撞体前缩近；这个碰撞体不阻挡角色的移动或拳脚。若镜头起点已经进入翼膜范围，镜头会找外侧安全位置，并暂时淡化翼膜，离开后恢复。镜头贴近角色时暂时隐藏角色网格，近裁切为 0.05 米。第一人称保持肩部原位。

营地建筑的脚底支撑通过 `NativeCamp.support_height_at(x,z,max_y)` 查询已导入 GLB 的真实三角面；地面行走会在碰撞胶囊半径前方探测台阶，在净空允许且台阶高度不超过 0.62 米时抬脚跨过。查询不到建筑地板时继续使用六公里盆地原有地形高度。空中降落也能落在建筑地板上。

`apply_hit(direction, amount)` 负责扣血和击退；致命伤 3 秒后在营地复活，避免存下零生命后无法游玩。`snapshot()`/`restore()` 保存位置、朝向、飞行状态、灵息、生命、速度与境界；读取境界时限定在 R4–R9，旧存档缺少此字段时使用当前境界。`teleport_to_ground(x,z)` 提供地面传送，清理上一次飞行的速度与击退但保留灵息。

R3 的 `receive_combat_hit(event)` 接收 Main 已确认命中的伤害事件，返回是否命中、实扣伤害、是否格挡/破防、是否打断和是否战败。普通格挡保留 25% 伤害与击退；破防解除格挡、承受全额伤害并至少硬直 0.8 秒。旧 `apply_hit(direction, amount)` 仍转接同一受击规则。受击会取消尚未结束的拳脚与武技，避免之后补结算旧攻击。

`blink_to(target)` 供更高境界的瞬移规则调用。调用方先检查境界、消耗、冷却与整段路线；角色模块再次检查终点坐标、地面/空中净空、2 公里离地上限、地形及营地真实网格碰撞。目标恰在营地地板上时识别为落地；成功后原子清除旧速度、加速、受击与攻击状态，返回 `true`。失败不改任何角色状态。远距离返地使用单独的 `blink_to_prepared_surface(requested_target, ticket)`：必须先由 World 签发并消费一次性实体地面票据，玩家再复核目标、可载入的干地支撑与胶囊净空；普通 `blink_to` 的距离和净空规则不因该入口放宽。

普通 C／Shift+C 从高空下降时，根据实际离地高度、前方地形／海面与障碍净空、当前下降速度和下一物理帧位移计算刹车包络。接近地面前约 100 米回到低空速度，Shift+C 的低空参考上限约 117 米／秒，普通 C 约 65 米／秒；着地前再降速。前方未载入的地块先请求流式载入并保持安全位置。普通 C 仅着陆，不触发爆破范围、伤害或地形变形。R6 及以上的主动冲击落地走 `begin_descent_strike(serial)` 独立入口：只在已载入的干地、离地 4–160 米且完整落地路径可行时开始；真实干地接触只发一次 `descent_strike_landed`，受伤、超时、海面或路径阻挡发 `descent_strike_failed`。范围伤害和地形变化由术法与 World 在接触后判定。

R3 战斗入口 `play_combat_action(profile)` 接受动作模块的释放时刻与收势时长，地面和空中都可起手；地面施法先制动并把水平速度限制在 0.25 米/秒，避免固定支撑脚随跑步滑动。成功时递增 `combat_serial` 并记录 `combat_action_id`。`combat_socket_transform_world(socket)` 转发当前可见骨架的骨点变换，`cancel_combat_action()` 在受击、传送、上车等打断时使当前序号失效。原有 `play_air_cast(windup)` 仍保留空中旧入口及释放后可接下一招的 0.24 秒旧收势兼容行为。Space 只由玩家的地面跳跃逻辑读取，施法仍由主场景的 R 键处理。

## C2 角色动作与 R3 手部武技

主场景在 `Player/Model` 下只实例化一套可见的 `assets/motion-r2/c2-motion-r2.glb` 角色。R3 保留 C2 原 19 个身体骨的休息姿态和袖口以上造型，仅替换原融合指团，增加双掌与 30 节指骨，共 51 骨、29 个动作片段。闭拳、张掌与刀手由真正的手指蒙皮变化完成。`NativeMotionR2.update_from_player(dt, player)` 每帧统一驱动；另有一套不渲染的步态采样骨架。旧 `assets/c2-motion.json` 留作历史数据，不再驱动第二套可见角色。既有生成参考图与本地 Blender 来源、时序、正常速度证据见 `assets/motion-r2/R3-MOTION.md`。

地面使用 idle、walk、jog、sprint 独立动作，按角色局部前后左右速度混合；空中连续采样既有的 `cruise` 与 `boost` 成片，并按实际切向／径向速度混合。旧分支只在 `boosting=true` 时选择前倾片段，灵息降到 Shift 门槛后即使角色仍以数百米每秒飞行，也切回接近直立的 `cruise`，造成长飞后突然直立。现在悬停直立、巡航保留前倾、加速进一步前倾、主动下潜和爬升分别选姿；空中施法／受击完成后过渡回当时的飞行姿态，不锁定下蹲。左键三段使用 jab、cross、kick；`play_attack(combo_index)` 映射 0、1、2，接触延时分别为 0.15、0.19、0.27 秒。每段保留髋部发力、支撑腿和完整收势；移动出拳以小幅步移配合足部支撑，空中拳脚使用独立动作。短暂的 `combat_ready` 姿势连接连续招式与静立。施法、普通移动与飞行动作仍只由一个适配器时钟推进。

Ctrl 慢走、普通跑动和 Shift 冲刺分别匹配 1.6/6.8/10 米每秒，完整步态周期步幅为 1.2/3.0/4.0 米；相位由实际水平速度推进。支撑脚按接触相位在世界坐标锚定，摆动脚释放，保留脚跟接触与推离滚动、反相摆臂和 0.15 秒地面过渡。五类武技分别为 R4 右拳、R5 左掌、R6/R7 右手横扫、R8 举臂下劈、R9 双臂举起后右掌下压；每类都有独立地空片段，归一化释放点 0.50，原拳脚仍为 0.38。`hand_l/hand_r` 现在直接读取掌骨，供蓄势特效随真实手部移动。

主场景允许接触后的恢复期衔接下一击，最后 0.16 秒内的左键输入会暂存一次；停手超过 1.15 秒，下一击重新从左拳开始。地面出招水平速度限制为左拳 0.5、右拳 0.35、上挑腿 0.08 米/秒，避免原先 6.8/10 米/秒跑动叠加固定拳脚造成滑步。真实命中才短暂停住攻击者与裂翼兽的动作，落空不暂停。角色受击、成功瞬移或上车会取消尚未接触的拳脚／术式，避免动作被打断后旧伤害仍然结算。普通受击只水平滑退；强击飞才给物理胶囊一次向上的冲量，并按实际离地高度切换空中受击与落地动作。格挡受击保持护头。

地面左直拳与右直拳在各自接触前，各带最多 0.18 米的短踏进，由角色物理胶囊实际移动并通过地面路径检查与 `move_and_slide()` 阻挡；踢腿不再追加踏步。空挥也执行同样的有限步幅，不向目标吸附。可见腰胸发力与前脚踏进共同决定最终出拳射程；命中仍由接触帧的手套骨点到兽体间隙决定，不能用放大不可见手套半径代替。新动作在 2.3 米起手时手套间隙约 0.15 米，属于真实接触；2.6 米起手时约 0.45 米，仍会落空。

近身伤害在权威接触帧读取当帧左／右腕或踢腿脚踝世界点，与裂翼兽原有 `RiftwingBody` 网格的身体包围盒计算最近距离；拳允许 0.24 米手套半径和容差，踢腿允许 0.30 米靴长与容差。原有朝向、高度和 3 米粗筛仍生效；只要手脚与兽体尚有超过对应半径的实际间隙就会落空，2.0 米起手的三段攻击仍可命中。这是稳定的身体命中体近似，并非逐三角形蒙皮碰撞。

`play_air_cast(windup)` 是旧验证和存档兼容入口：R4/R5 气刃、R6/R7 领域弧环、R8 破虚裂隙、R9 分段道环仍可由测试直接调用，其 R2 GLB 由 `NativeVfxR2` 控制。玩家按 R 则走上文 R3 武技路径；`NativeMain` 仍以范围、遮挡、灵息和冷却决定伤害，特效不充当碰撞或伤害判定。R6–R9 瞬移门仍沿用原有独立特效。

## 验证

1. 用 Godot 4.6 打开 `godot/project.godot`，运行主场景，检查角色双脚落在地形上；WASD、Space 和 V 有效。
2. G 起飞，松开 G 应悬停；抬头按 W 应同时前进和上升，低头按 W 应前进和下降，A/D 仍侧移。低空不按 C 只低头按 Shift+W，应在约 0.42 米净空悬飞而不撞地；按 C 或 Shift+C 应下降并落地。再从约 350 米分别按 C、Shift+C，观察约 100 米开始的平滑限速和着地前再次减速；普通 C 不应出现冲击特效或坑。Space 不会起飞或施法。
3. 第三人称低空按 Shift+W：身体整体前倾；持续 Shift+A/D：侧倾连续无突然回正。持续 Shift+W 到灵息跌破加速门槛，角色仍在前进时应由加速姿态平滑转为巡航前倾，松开 W 停稳后才回到直立悬停；再比较爬升、低头下潜、空中 R 施法后恢复的姿态。到 350 米以上比较 HUD 的巡航/加速速度。地面按 Ctrl 应精细步行，松开后恢复普通步速。
4. 在盆地边缘、高坡和地形块交界处飞行，检查未穿地、未超出约 3 公里边界，也不会超过 2 公里离地高度。
5. 从营地南侧沿指挥舱或医疗舱入口正中向北走：角色应跨过真实台阶，站在约 0.8 米高的室内地板上；走出后应重新贴地。地图其他位置的地形高度不受营地支撑影响。
6. 从 Shift 冲刺中左键出拳：角色应迅速制动并以真实短踏步出拳，脚下保持支撑；在每击收势前再点左键，应依次衔接左拳、右拳、上挑腿。距离兽体仍有明显间隙时应提示落空；贴近后每击只扣血一次，短踏步不能穿过墙。按住右键格挡并受击时保持护头；普通受击只滑退，强击飞时 HUD 的离地高度应与动作一致。攻击蓄力中被兽打断后不应再补结算旧伤害。地面和起飞后分别按 R，看蓄力抬手、手部释放源和短行程命中。按 F6 切到 R6，F5 保存并重开，核对位置、朝向、灵息、生命与 R6 境界；武技和瞬移冷却均应恢复。
7. 灵息约 21% 时在地面按住 G：HUD 应显示约一秒回息，达到 25% 后自动升空；松开 G 停在约 0.4 米时 HUD 显示 `0.4` 米，再按住 G 上升。按 C 落到营地地板后再次按 G 应能起飞。Space 只跳跃。
8. 在指挥站侧墙外靠近墙体，左右转身和上下抬头：第三人称镜头应缩近且不钻入黑色墙面；在裂翼兽近身战时绕到其翼侧，镜头应缩近而不穿过翼膜。沿墙角斜走、四向碰墙以及空中 Shift 加速斜飞遇墙时，角色应停住或沿墙滑行。可运行 `--headless --path godot --script res://tests/native_mobility_verify.gd` 与独立的 `native_mobility_independent_verify.gd` 复查，均使用单独的测试档。
9. 在原生主场景检查步行、约 6.8 米/秒慢跑、10 米/秒冲刺和四向移动；连续拳、拳、踢后确认只有接触帧扣血。按 F2 到裂翼岭，R4 拳劲从右手飞向准星；按 F6 依次到 R5 左掌、R6/R7 横扫、R8 下劈、R9 压掌，核对各境界的地空动作、特效、蓄力时间、消耗与伤害。按 F3 重置对手再打，重置后按 H 不应重复产出掉落。`native_r3_skill_verify.gd` 用真实 Godot 物理帧覆盖释放、命中、打断、冷却和存档；`native_r2_main_independent_verify.gd` 覆盖旧单套可见骨架、动作时钟、接触伤害、御空回息和镜头；`native_air_cast_verify.gd` 覆盖旧 R2 兼容入口。Windows 可在仓库根目录运行 `py -3 godot\tests\capture_native_r2_main.py`，以隐藏的 OpenGL 窗口向 `godot/reports/r2-main/` 输出历史 R2 主场景 PNG，不占用当前试玩窗口。
10. 运行 `--headless --path godot --script res://tests/native_combat_flow_verify.gd`：它在独立档位用真实 60 Hz 物理帧验证冲刺起手的逐击位移、2.0/2.3 米真实接触与 2.6 米落空的手套间隙、连击缓冲、普通与强受击、格挡、命中停顿和打断取消。连续主场景取帧及逐帧事件记录见 `godot/assets/motion-r2/evidence/`。

## 连续星球玩家适配

`NativePlanetCoordinates` 按网页星球契约保存双精度 canonical 坐标，半径为 120,000 米；原盆地 `(x,y,z)` 映射到 canonical `(120000+y,-z,-x)`，因此旧营地和旧存档位置有确定的对应点。Godot 物理坐标仍为场景局部坐标。`NativePlayer` 逐帧按所在位置的径向重力方向对齐身体，地面移动沿球面切线，飞行则沿球面弧线推进，并向世界查询目标地块的实体网格与扫掠净空。G/C、Shift、Space、攻击和格挡入口保留。

新增 `teleport_to_surface(scene_pos)`、`snapshot_canonical()` 和 `restore_canonical(player_data, planet_data)`，供主场景在星球身份和目标地块加载就绪后传送、保存及恢复。`snapshot()`、`restore()`、`teleport_to_ground(x,z)` 保留旧接口；盆地内旧档仍可落到对应位置。飞行的 2,000 米上限是相对当前球面实体地形的离地高度；上文约 3 公里边界的检查仅属于旧六公里盆地阶段，连续星球应改测越过旧边界、海岸、极区和背面。

### 外天空飞行方案

独立旧盆地模式的 `MAX_AGL=2000` 保持兼容。接入真实球面的盆地也可继续向外天空飞，球面另设 `PLANET_MAX_AGL=180000`；离地 2–10 公里平滑接入高空巡航，低空的 G/C、Shift、Space 和攻防手感不跳变。R4 高空巡航速度约 3360 米/秒，R9 约 5760 米/秒；升降速度随境界与高度增加，使正常按 G 可在约一分钟进入看见整颗工程半径 120 公里星球的外天空。高空 Shift 能耗降低，普通御空仍缓慢耗能，25% 起飞灵息足够完成一次正常升空。放开 G 后逐渐制动并停升，按 C 返程；下降速度按离地高度和实际制动距离限制，接近实体地形恢复低空速度，再以 C 落地。所有位置仍要目标地块可见且可碰撞、沿实际路径扫掠；未加载时保持安全位置。`flight_ceiling()` 提供当前世界的离地上限给主场景和术法。

高空闭环的验证步骤：在营地附近 G 起飞，持续按 G 穿过 2/10 公里并观察高空速度与 HUD，继续到超过 120 公里验证可见球体及无平面边；松开 G 检查停升，持续按 C 检查分段制动与地形上方净空，最终落地后再次 G 起飞。保存高空档并重启，确认 canonical 位置、方向、速度和灵息恢复；同时重跑旧盆地 G/C、Shift+C，并在独立旧盆地模式复查 2 公里兼容上限。该方案必须等世界球体网格、远景和主场景相机接好后用真实物理帧与画面共同确认。
