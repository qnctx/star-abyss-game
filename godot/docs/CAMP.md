# 营地建筑迁移

`scripts/native_camp.gd` 复用浏览器版 `playable/src/camp-v2/layout.mjs` 的三栋正式建筑，位置、朝向与地面贴合方式不变。原始美术基于 [营地建筑概念图](../../docs/art/camp-v2/camp-architecture-reference.png)，此次直接导入已完成的 GLB，没有重新制作模型。Godot 导入所生成的纹理 PNG 是同一模型的依赖。

| 建筑 | 原版中心 `(x,z)` | GLB SHA-256 | 实际三角面数 |
| --- | ---: | --- | ---: |
| 指挥站 | `(-17,174)` | `285f2baabf252b2b5946fb451ccf6e565f347d9b55139b45f0282904d957475c` | 7,712 |
| 医疗站 | `(4,174)` | `039be2bf53a81f07f0d327c9ecc26200be5588e1439d1e9e3ba9b018cdc179d0` | 7,324 |
| 工坊 | `(20,174)` | `8c7b659fed98e0b77e2eb1e46d143156105e1091311ace1dd4897be93c027293` | 9,680 |

调用 `NativeCamp.new()` 后将其加入主场景，再执行 `camp.setup_camp(world)`。每栋建筑以已导入网格的最低点贴合 `world.height_at`，每个可见网格也提供对应的凹面静态碰撞。门洞没有用矩形代理堵住。`support_height_at(x,z,max_y)` 从 `max_y` 向下查询这些真实三角形，返回最高可命中的营地表面；无命中时返回 `-INF`。角色应把它和普通地面高度一起用于脚底支撑，并以当前脚底高度加允许的上台阶高度传入 `max_y`。`set_enabled(false)` 会同时关闭显示、支撑查询和物理碰撞。

独立 Godot 4.6.2 headless 实测：三栋各 8 个网格完整导入；指挥站入口中心 `x=-17` 与医疗站入口中心 `x=4` 在身高 `y=1.5` 的水平射线下通行，离中心 3 米的墙体会阻挡。指挥站台阶沿 `z=179 → 178 → 177.25` 的高度分别为 `0.2222 → 0.7022 → 0.7572` 米；医疗站在 `(4,177.25)` 为 `0.7572` 米；工坊在 `(20,177.25)` 为 `0.7572` 米。关闭模块后墙体射线不再命中，支撑查询返回 `-INF`。

完整场景实测步骤：从营地前方沿 `+Z` 朝三栋建筑走，进入指挥站与医疗站中央门洞，再横向走向墙体确认受阻；沿台阶进入时观察脚底是否落在对应台阶和地板上。工坊前方有模型自带柜台，靠近工作点 `(20.55,177.3)` 检查其碰撞，不把柜台视作开放门洞。
