# 2026-09-12 桌面移动与视角控制

当前浏览器游戏采用 PUBG 端游常见的键鼠分工。按键依据 [PUBG 官方基础操作说明](https://support.pubg.com/hc/en-us/articles/360002074913-What-are-the-basic-game-commands)；下列速度和响应数值为本项目调校，不代表 PUBG 的内部物理参数。当前任务是移动控制，未增加枪械、开镜、装填或自动翻越系统。

| 按键 | 当前行为 |
| --- | --- |
| WASD | 前后移动、左右侧移；鼠标改变身体朝向和行进方向 |
| 按住 Shift + W | 站立疾跑，可以同时移动鼠标转弯 |
| 按住 Ctrl | 慢走，优先于 Shift；松开恢复常速 |
| C / Z | 蹲伏 / 趴下，再按同键起身；空中及驾驶时不可切换 |
| Space | 轻按跳跃；长按至少 0.30 秒转助推，松开缓降；驾驶时刹车 |
| Q / E | 扫描 / 已解锁矢量闪避；不再探身 |
| 按住 Alt | 独立环视，身体和行进方向不变；松开镜头平滑回正 |
| = | 自动前进开关；W/S、暂停、打开地图、切出窗口会取消 |
| V | 步行与驾驶均可切第一 / 第三人称；驾驶偏好独立保存，下车恢复步行偏好 |
| F | 调查、修复、上下车 |
| M | 地图；保留 Tab 作为旧版地图快捷键，未把它伪装成背包 |
| G / L | 直接助推 / 肩灯；X/B 保留为扫描/闪避旧键别名 |
| J / U / Esc | 调查记录 / 进化 / 暂停 |

## 手感与动作

2026-09-12 趴卧重做：分段趴下/起身、弯肘支撑和交替屈膝爬行，第一人称眼点跟随实际头部。下车立即重置独立环视并对齐身体方向，走跑转向无需先按 Alt。对应 3D、截图和复测见 [趴卧重构](PRONE_REDESIGN.md)。

- 地面常速前 / 侧 / 后为 4.7 / 3.2 / 2.8 m/s；站立疾跑 6.3 m/s。慢走为 1.65 / 1.3 / 1.2 m/s。斜向归一化，不叠加速度。
- 蹲伏速度系数 0.52，趴下 0.18；低姿态不能疾跑。前向起步指数响应 10/s、反向制动 16/s、松键制动 20/s，正常疾跑停止距离小于 0.35m。
- 跳跃初速 4.9m/s、重力 14m/s²，平地最高约 0.86m；具有空中转向、地面/障碍碰撞与落地缓冲，不消耗助推能量，也不会长按连跳。
- 蹲伏采用已有 Quaternius CC0 全身蹲伏/蹲走片段；跳跃使用已有 Jump_Loop。趴卧及爬行动作为本地骨骼动画，非 PUBG 原版动捕。现有原生 C2 模型、骨段长度和贴图保留。
- 第一、第三人称共用观察目标，镜头高度随姿势平滑变化。无法锁定鼠标时支持按住左键拖动；趴下第三人称支点保留地面间距，避免触地隐藏角色。
- 趴卧使用前中后三点的身体占地检查；站起前检查净空。存档保留合法姿势；不会恢复按住的 Ctrl/Alt、自动前进或助推输入。旧存档缺少姿势时站立。

## 复测

1. 刷新 `playable/star-abyss.html`，继续调查，按 V。W+Shift 跑动中移动鼠标，确认连续转弯；Alt 环视后松开，确认跑步路线不突变。
2. 按住 Ctrl+W 慢走，松开 Ctrl 加速；按 C 检查蹲伏和蹲走，按 Z 检查趴卧和爬行，再按 Z 起身。
3. 第一人称默认空手；Q 取出扫描器、扫描、合拢并收回。E 使用已解锁闪避。Space 轻按起跳，长按转助推，松开缓降；G 可直接助推。
4. = 自动前进，S 取消；M 打开和关闭地图；切出窗口后返回，确认无粘键和自动跑动。
5. 靠近可调查目标按 F；修车后检查 W/S 油门、A/D 转向、Space 刹车、F 下车。测试窄窗口下 C/V/M 按钮点击和中文提示。

扫描器设计图、Blender 源文件、动作时序及当前实测见 [第一人称装备说明](FIRST_PERSON_EQUIPMENT.md)。

驾驶现已支持真实座椅第一人称、随车转动的镜头和握把、实时车速/电量仪表；图与同车 GLB/Blender 源文件见 [驾驶第一人称](VEHICLE_FIRST_PERSON.md)。
