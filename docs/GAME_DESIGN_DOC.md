# 🪐 星渊迷航 (Star Abyss Voyage) — Game Design Document

> **一句话定位：** 深海迷航 × 塔防 × 星空——在毒气星球上，氧气就是生命，塔防保卫基地，探索解开谜团，最终逃离深渊。

## 0. 当前 MVP 执行版（2026-06-09）

这部分用于指导当前代码开发。下面内容优先级高于远期愿景章节；远期内容仍保留作为方向。

### 0.1 当前已实现核心循环

当前可玩循环是：

```text
白天探索/采集 -> 建造基地模块 -> 夜晚防守 -> 击杀/守住基地 -> 继续扩建
```

### 0.2 当前 MVP 设计目标

当前阶段不追求完整沙盒，而追求一个“能反复玩 10-15 分钟”的闭环：

1. 玩家白天采集基础资源。
2. 玩家选择建造路线：防御、氧气、护盾、能量。
3. 夜晚敌人进攻基地，玩家用武器和建筑防守。
4. 防守奖励和基地损伤推动下一天的建造选择。
5. 能量与蓝图开始承接科技树，先用于解锁护盾和控场建筑，而不是只停留在资源堆积。
6. 后期用 Signal Beacon 把 energy/blueprint 消耗转成“求救信号”长期目标。

## 1. 游戏概述

### 1.1 基本信息

| 项目 | 说明 |
|------|------|
| **暂定名称** | 星渊迷航 (Star Abyss Voyage) |
| **游戏类型** | 第一人称 / 第三人称 生存·探索·塔防 |
| **核心体验** | 深海迷航式的孤独探索 + 基地塔防的紧张节奏 + 星空神秘叙事 |
| **目标平台** | PC (Steam), 后续可扩展至主机 |
| **单局时长** | 主线 20-40 小时 |
| **画面视角** | 第一人称为主，建造模式下可切换第三人称 |

### 1.2 灵感来源

| 游戏 | 借鉴元素 |
|------|----------|
| **深海迷航 (Subnautica)** | 氧气管理、水下探索感、孤独生存、渐进式解锁区域 |
| **异星工厂 (Factorio)** | 自动化生产线、资源管理 |
| **王国保卫战 (Kingdom Rush)** | 塔防布阵策略、敌人波次设计 |
| **森林 (The Forest)** | 生存建造、日夜循环威胁 |
| **星际拓荒 (Outer Wilds)** | 探索驱动叙事、神秘氛围 |

### 1.3 核心循环

```
探索新区域 → 发现资源/线索 → 收集材料 → 返回基地
     ↑                                        ↓
     ├── 理解更多故事 ←── 发现遗迹/日志 ←── 制造装备
     ↓                                        ↓
  解锁新区域 ←────── 升级科技 ←────── 抵御袭击（塔防）
```

## 2. 世界观与故事

### 2.1 背景设定

**时间：** 远未来。人类已迈入星际殖民时代。

**地点：** 未知星系·代号「深渊」的星球。星球表面被浓密的毒气包裹，大气含氧量为零。奇怪的是，星球地表之下存在大量洞穴网络，局部洞穴内竟有可呼吸的氧气。

**开局：** 你是一名星际货运飞船「白鸦号」的工程师。飞船在穿越「深渊」星系时遭遇未知能量冲击，船体解体。你在逃生舱中醒来，发现自己坠落在一颗陌生星球的表面。

### 2.2 核心悬念（逐层揭示）

| 阶段 | 揭示内容 | 触发条件 |
|------|----------|----------|
| **生存期** | 你发现自己不是第一个坠落的人——之前的遇难者留下了零散的日志和简陋的遗迹 | 探索 Crash Zone 周边 |
| **发展期** | 前人在此发现了一种极其珍贵的矿物——「虚空晶」，这或许是吸引飞船前来的原因 | 深入 Crystal Caves |
| **探索期** | 星球上存在远古文明的遗迹，比人类早数百万年。他们的科技远超人类 | 探索 Ancient Ruins |
| **觉醒期** | 虚空晶是远古文明制造的「钥匙」，星球本身是一座巨型监狱/实验室，关押着某种存在 | 深入 Abyssal Rift |
| **终局** | 你需要激活远古传送装置逃离——但激活它会释放被囚禁的存在。你有两个选择 | 到达 The Core |

### 2.3 两种结局

| 结局 | 选择 | 结果 |
|------|------|------|
| **牺牲结局** | 不释放囚禁者，用剩余能量发出求救信号 | 你在星球上等待救援，囚禁者继续沉睡。开放式结局，暗示救援可能到来。 |
| **解放结局** | 释放囚禁者，换取出逃机会 | 你成功逃离，但释放了一个未知存在到宇宙中。你的飞船上收到一条信息：「谢谢你，人类。我们会再见面的。」 |

## 3. 核心机制

### 3.1 三大资源

| 资源 | 作用 | 获取方式 | 上限 |
|------|------|----------|------|
| **氧气 (O₂)** | 探索的根本限制，耗尽即死亡 | 基地 O₂ 发生器、氧气瓶、O₂ 植物 | 基础 100s，最高 300s（升级后） |
| **能量 (Energy)** | 基地运转、防御设施、制造设备 | 太阳能板、地热发电机、虚空晶反应堆 | 取决于基地储能容量 |
| **虚空晶 (Void Crystal)** | 终极稀有资源，解锁高级科技 | 深渊裂隙深处、远古遗迹 | 有限，需谨慎使用 |

### 3.2 昼夜循环

- **白天（16分钟）：** 毒气风暴较弱，可见度高，资源刷新，探索窗口
- **黄昏（4分钟）：** 风暴增强，敌方活动增加
- **夜晚（12分钟）：** 毒气风暴最强，可见度极低，**敌方发动塔防袭击**，不建议外出探索

> 总周期 32 分钟 ≈ 一个游戏日

### 3.3 死亡惩罚

- 死亡时掉落携带的未保存资源（部分可找回）
- 在当前最近的安全屋/基地重生
- 已建造的建筑和研究进度保留
- 难度模式影响：
  - **探索模式：** 无掉落，只回退位置
  - **生存模式：** 掉落资源，需跑尸
  - **硬核模式：** 永久死亡

## 4. 氧气系统（核心创新）

### 4.1 氧气是探索的"血量"

```
┌──────────────────────────────────────────────┐
│  基础 O₂ 容量: 100s                           │
│  每件装备/升级增加上限                          │
│                                                │
│  ┌────┐  ┌────────┐  ┌──────────┐  ┌────────┐ │
│  │100s│→ │轻量气瓶│→ │中型气瓶  │→ │重型气瓶 │ │
│  │基础│  │+30s   │  │+60s     │  │+100s   │ │
│  └────┘  └────────┘  └──────────┘  └────────┘ │
│                                                │
│  总和上限可达 290s（≈ 5分钟探索时间）            │
└──────────────────────────────────────────────┘
```

### 4.2 氧气补给方式

| 方式 | 回复速率 | 条件 |
|------|----------|------|
| 基地内 | ∞（无限） | 基地有能量供应 |
| O₂ 据点（小型补给站） | 快速 | 预先建造在外面的补给站 |
| O₂ 植物（Pocket O₂） | 缓慢 | 装备可种植 O₂ 植物的背包模块 |
| 便携 O₂ 罐 | 瞬间 +60s | 消耗品，制造获取 |
| 残骸气瓶 | 瞬间 +30s | 地图随机刷新 |

### 4.3 影响氧耗的因素

| 状态 | 氧耗倍率 |
|------|----------|
| 静止/慢走 | 1.0x |
| 奔跑 | 1.5x |
| 战斗/工具使用 | 1.8x |
| 毒气风暴区域 | 2.0x |
| O₂ 效率升级后 | 0.8x |

### 4.4 O₂ 建造系统

玩家可以在星球表面建造 **O₂ 管道网络**：
- **O₂ 发生器**：基地核心建筑，产生氧气
- **O₂ 管道**：连接据点与基地，传输氧气（有距离限制）
- **O₂ 中继站**：延长管道距离
- **O₂ 补给站**：管道终端的消耗点，提供区域 O₂ 补给

> **设计意图：** 基地是"母舰"，管道是"脐带"，探索就是不断延伸脐带的长度。

## 5. 生存与建造

### 5.1 需求系统

| 需求 | 机制 |
|------|------|
| **氧气** | 核心需求，外出时持续消耗 |
| **食物** | 影响生命恢复速度，饥荒时缓慢扣血 |
| **水** | 影响耐力恢复速度 |
| **温度** | 某些区域极寒/极热，需要防护服 |
| **辐射** | 深渊区域有辐射，需要防辐射服 |

### 5.2 建造系统

#### 基地模块

| 模块 | 功能 | 前置科技 |
|------|------|----------|
| **核心舱** | 初始基地，不可拆除 | 开局自带 |
| **O₂ 发生器** | 为基地供氧 | Tier 1 |
| **太阳能板** | 白天发电 | Tier 1 |
| **储物舱** | 增加存储容量 | Tier 1 |
| **制造台** | 制造工具/装备 | Tier 1 |
| **研究台** | 分析材料，解锁蓝图 | Tier 2 |
| **种植舱** | 种植食物 & O₂ 植物 | Tier 2 |
| **防御炮台** | 自动攻击来袭敌人 | Tier 2 |
| **护盾发生器** | 为基地提供临时护盾 | Tier 3 |
| **地热发电机** | 持续高效发电 | Tier 3 |
| **虚空晶反应堆** | 终极能源，解锁终局科技 | Tier 4 |

#### 建造规则
- 模块之间需通过走廊连接
- 每个模块消耗能量和空间
- 毒气风暴可损坏建筑，需要维修
- 防御设施需布置在基地周边

### 5.3 载具系统

| 载具 | 功能 | 前置 |
|------|------|------|
| **探索小艇** | 快速在地表移动，轻微装甲 | Tier 2 |
| **深潜机甲** | 深入深渊裂隙，抗高压/辐射 | Tier 3 |
| **飞行背包** | 短途飞行，翻越障碍 | Tier 3 |
| **逃生飞船（零件x3）** | 终局目标 | Tier 4 |

## 6. 塔防系统

### 6.1 袭击机制

- **触发条件：** 每逢夜晚，敌方会发动一波袭击
- **袭击强度：** 随玩家科技等级和探索深度递增
- **袭击预警：** 黄昏时扫描器发出警报，显示来袭方向和强度
- **防御失败：** 基地建筑受损，资源被掠夺，但不会直接游戏结束

### 6.2 防御设施

| 设施 | 伤害 | 射程 | 特点 |
|------|------|------|------|
| **激光炮台** | 中 | 远 | 单体高伤，对装甲敌人有效 |
| **散射炮台** | 低 | 近 | 范围攻击，清小怪 |
| **减速力场** | 0 | 中 | 减速 50%，无伤害 |
| **导弹塔** | 高 | 超远 | AOE 爆炸，CD 长 |
| **虚空水晶塔** | 极高 | 全图 | 终极防御，消耗虚空晶充能 |
| **陷阱地雷** | 中 | 单体 | 一次性，触发爆炸 |
| **电击围栏** | 低 | 近 | 墙体型，持续伤害接触者 |

### 6.3 敌袭类型

| 波次 | 敌人类型 | 特点 |
|------|----------|------|
| **侦察波** | 小型侦察虫 | 数量多、速度快、血量低 |
| **突击波** | 装甲冲击兽 | 血厚、直奔基地核心 |
| **空袭波** | 飞行翼兽 | 无视地面障碍，压制防空 |
| **混合波** | 侦察虫掩护 + 投石巨兽后排 | 需策略布阵 |
| **BOSS 波** | 深渊巨兽 | 单一目标，极高血量，突破防线需集火 |

### 6.4 塔防与探索的平衡

> **设计哲学：** 塔防是生存的"考试"，考验你这段时间的建造和准备成果。不是无休止的塔防——白天是探索和建造时间，夜晚是防守时间。如果不想防守，可以建造足够强的自动化防御。

## 11. 美术风格方向

### 11.1 整体风格

- **Sci-fi survival horror aesthetics**
- 参考：深海迷航的孤独美感 + 异形/普罗米修斯的科技神秘感
- 色调：星球表面偏冷色调（毒气氤氲的紫色/墨绿），洞穴内多彩荧光，遗迹区域金色/白色
- 毒气效果：大面积体积雾，动态密度变化

### 11.2 关键视觉锚点

| 视觉元素 | 描述 |
|----------|------|
| 毒气天空 | 永不散去的浓密气云，偶尔透出星光 |
| 荧光生态 | 洞穴和森林区域的生物发光，营造异星美感 |
| 远古建筑 | 几何感强烈、材料不明的建筑残骸 |
| 虚空晶 | 散发深紫色光晕的晶体，核心视觉符号 |
| 基地灯光 | 在毒气中亮起的基地是唯一的"家"的象征 |

## 12. 技术方案建议

### 12.1 推荐引擎

| 引擎 | 优势 | 劣势 |
|------|------|------|
| **Unreal Engine 5** | 画面表现力顶级，Niagara 粒子适合毒气效果，Lumen 光照适合洞穴荧光 | 学习曲线陡，团队要求高 |
| **Unity** | 生态成熟，教程丰富，适合小团队 | 画面天花板较低，需大量插件 |
| **Godot 4** | 开源免费，轻量，适合独立开发 | 3D 大场景优化不如 UE |

> **建议：** 如果是学习/独立开发项目，选 Unity 或 Godot；如果目标是商业级画面，选 UE5。

### 12.2 关键技术难点

| 难点 | 解决方案 |
|------|----------|
| 大范围体积雾性能 | UE5 体积雾 LOD / 分块加载 |
| O₂ 系统实时扩散模拟 | 简化模型：O₂=可建造的"补给区"，不做流体模拟 |
| 塔防 AI 寻路 | NavMesh + 动态障碍物更新 |
| 昼夜切换 + 风暴效果 | Timeline + 材质参数过渡 |
| 大型洞穴无缝加载 | World Partition (UE5) / Additive Scenes (Unity) |

### 12.3 MVP 范围建议

如果是最小可行版本，建议先做到：
1. Crash Zone 地图 + 基础建造
2. O₂ 系统（基本版）
3. 3 种防御塔 + 3 种敌人 + 简单波次
4. 1 种载具
5. 基础昼夜循环
