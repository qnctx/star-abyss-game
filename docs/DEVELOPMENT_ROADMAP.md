## 1. 阶段计划

|阶段|依赖|交付物|通过条件|
|---|---|---|---|
|M0 基线审计|无|场景/模块/资源清单、性能基线、旧档样本、已知问题表|锁定参考设备、当前入口和保留数据；逐项分类而非直接删文件|
|M1 3D样板|M0|一段室外到舰内连续路线、统一角色动作/材质/碰撞|多角度无缺面、通道可走、脚底合理、近墙镜头与载具一致；连续动作人工确认|
|M2 能力底座|M1|生命/共振/技能状态机、有效事件、闪避五境界测试夹具|无穿墙、无重复结算、暂停冻结、升级不清冷却；高级状态仅夹具，不当正式进度|
|M3 三解法遭遇|M2|一只明确前摇守卫、贯击/屏障入门、可绕行关卡、失败恢复|不指定专精也可完成，三种解法确实不同，死亡/重试不丢唯一物品|
|M4 成长闭环|M3|样本研究、熟练度、条件突破、U技能/配装、存档迁移|发现→解锁→使用→验证→突破→保存完整；旧续航保留；材料不软锁|
|M5 表现与扩展|M4|样板五境界3D效果、其余技能下一境界规格、第二种环境|画面、判定、音效一致，低画质保留关键信息，资源生命周期通过|
|M6 行星章节|M5|多区域联系、远征准备、跨区域信息反馈|新区域有独特规则且影响探索，不复制终端流程；同预算路线测试|

星际、文明阵营、领域属于M6之后的独立规划，不预造空菜单或虚假进度条。

## 2. 每个开发切片的工作单

必须填写：目标/不做什么、受影响模块、数据版本变化、玩家输入与反馈、资产来源、失败路径、测试计划、替代旧代码、运行证据、未通过项、用户复验步骤。角色可由同一开发者承担，不要求虚构团队。

顺序：读取规范与现有代码 → 建立最小规则测试 → 实现真实闭环 → 接入表现 → 浏览器验证 → 检查旧功能 → 清理替代实现 → 更新文档。测试失败先判断产品还是旧断言不适配，禁止为变绿删除重要行为断言。

## 3. 核心测试矩阵

|类别|具体检查|证据|
|---|---|---|
|空间|角色绕舰正侧背、进出门、斜坡/石头、镜头碰撞|实际WebGL多角度图与连续操作|
|动作|走跑四向、急停/转身、起飞/落地、技能中断|连续片段，不能只看静止帧|
|技能|不足资源、冷却、同帧双输入、顶墙、低帧率|纯规则测试＋真实键鼠整合|
|屏障|正面、侧面、背面、破裂溢出、移除|方向判定测试＋场景命中证据|
|成长|去重、防刷、条件不足、重复确认、取消突破|状态快照与事务测试|
|存档|旧档、坏字段、重复读写、迁移失败备份|隔离浏览器存档，禁止污染用户档|
|UI|Tab/J/U职责、关闭返回、捕获失败提示、640/768/1440宽度|按钮可点、中文不裁剪、无遮挡截图|
|驾驶|鼠标不改车向、W/S与A/D、刹车下车、暂停|实际输入与位置/车向断言|
|性能|常规/最坏技能同屏、200次释放、区域切换|硬件信息、帧耗时与资源趋势|
|主线|无专精替代路线、失败恢复、任务物品唯一性|端到端路线，不用传送冒充通关|

## 4. 当前可用命令与新增测试方向

2026-09-08 已新增按玩法入口 `npm run test:feature -- --list` 和完整回归 `npm run test:release`。后者自动发现所有规则/浏览器用例并输出独立报告；单项通过与全量自动化通过分开，不自动发布。具体命令、夹具边界及人工上线条件见 [玩法测试指南](GAMEPLAY_TESTING.md)。

当前构建：`npm run build`；逻辑：`npm test`；浏览器：`npm run test:e2e`。测试入口在 playable/tests/。查看 package.json 的实际清单，不凭文档认为新增文件已纳入默认命令。

未来新增能力/成长/特效生命周期测试时同步默认套件；夹具必须标明是否授予等级、移动角色或设置剧情。手测观感与脚本通过分开报告，测试通过不等于自然度、平衡与美术已获用户接受。

## 5. 发布与回滚

发布前确认：源码与产物一致、版本标记更新、资源引用有效、没有运行错误、旧档可恢复、已替代代码清理完成、文档写明本轮实际测试结果。不得把历史全套通过次数计入本轮。

变更需要迁移时先保留旧档序列；失败不得覆盖原档。规则回退与存档回退分别处理。离线包保留可定位的构建标记，用户刷新后可确认是否确实拿到新版。

## 6. 首次用户复验脚本（待对应阶段实现）

1. 新档与旧档各进一次；旧冲刺/飞行等级保持，未赠送未知技能。
2. 走过同一室外—门洞—舰内路线，绕看岩石与舰体，四向走跑和转身。
3. 用入门闪避避开一次威胁；顶墙不穿过；空放不涨有效熟练度。
4. 取得样本，回安全点查看条件；熟练度满但未验证时不能突破。
5. 完成验证并确认升级；资源和冷却不重置，重载后进度正确。
6. 同一遭遇分别绕行、攻击、防守完成；失败后可重试且任务不软锁。
7. 对比技能不同境界的实际3D表现，从正侧背观察，确认高级效果不遮挡。
8. 打开Tab/J/U、暂停、返回、驾驶环视；无输入残留和资源补算。
