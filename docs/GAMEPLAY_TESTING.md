## 快速开始

在项目根目录打开终端。已安装依赖的本地项目可直接运行；新机器先执行 `npm ci`，再执行 `npx playwright install chromium` 安装测试浏览器。

```bash
npm run test:feature -- --list
npm run test:feature -- dash
npm run test:feature -- vehicle --headed
npm run test:feature -- evolution
npm run test:release
```

`--headed` 会打开专用测试浏览器，让你观看自动操作；不要在自动运行时抢按键，它不是手动沙盒。浏览器使用 Playwright 新建的隔离上下文，不连接日常浏览器资料目录或覆盖你的游戏存档。正常离线存档回归也只写这个临时测试上下文。

每次默认先构建最新 game.js，再执行对应规则测试和浏览器测试。想快速检查规则可用 `--rules-only`，但结果明确标记为不具备发布资格。`--plan` 只显示本次会跑哪些文件，不构建也不执行；拼错玩法或选项会报错，不会悄悄跑别的测试。

旧命令 `npm run test:e2e` 也已接入同一个完整入口，不再维护重复的浏览器文件清单；现在会先跑规则再跑浏览器。单项和全量报告不会因为共用入口而互相覆盖。

### C2 方向与角色专项手测

本切片版本为 **C2-ASSET-PERF-20260908**。执行 `npm run test:feature -- movement`，或追加 `--headed` 观看隔离自动操作。最终代码 Node 253/253 通过（20.4 秒）；movement 单次门禁规则 119/119、浏览器 14/14 通过（690 秒），状态 FEATURE_PASSED_NOT_RELEASE，前后指纹一致。119 项为全量规则子集，不重复计数；旧 246 项与分批浏览器计数仅作历史。最终结果以 HTML5_VERIFICATION.md 为准。

1. 刷新游戏核对版本、继续原档，V 切第三人称。按住 W 同时移动鼠标看左右 / 身后，人物路线应不变。S 倒走、A/D 真侧移，不应自动转身前进。
2. 按 ←/→ 转身体，松开后 W 应沿新身体前方移动；再鼠标环视，身体前方不变。暂停并继续 / 读档，确认身体 heading 与观察 yaw 各自保留；旧档缺 heading 从 yaw 迁移。
3. C 切慢走重试四向；常速前 / 侧 / 后为 4.7 / 2.4 / 2.2 m/s，慢走 1.65 / 1.3 / 1.2 m/s，斜向连续混合。仅前向含前斜可 Shift 冲刺，纯侧 / 后退不得变为冲刺。已解锁 R 闪避也按身体方向而非鼠标方向。
4. 持续跑 10 秒并左右 / 向后环视，分别在舰内外观察材质清晰度、视锥边缘岩石、动作和卡顿；验证 Tab 返回鼠标捕获、Space 起飞 / 着陆与上车 / 下车。驾驶仍为 W/S 油门及倒车、A/D 转向、鼠标环视。元婴自身飞行时按住 C 下降、松开悬停；地面 C 蹲伏、Ctrl 慢走，车上 C 不改变车速。
5. `npm run preview:avatar` 重建后打开 [实际 C2 角色验收页](ui-implementation/c2-character-preview.html)，逐一检查 6 动作、播放 / 单步和八角度。对照 [造型图](ui-concepts/c2-independent-20260908/turnaround.png)、[动作图](ui-concepts/c2-independent-20260908/keyposes.png)，检查矿壳附着、正背侧轮廓、肘膝弯曲、重心转移和脚底接触。

角色是程序化矿壳 / 织物模型，不是概念图级扫描资产；后退 / 侧移是全身前进片段的解析重定向，非新增独立动捕。八角度自动检查不等于所有地形、所有动作相位都无穿插；需人工判断松弛感、滑足和连接处。专项通过不等同上线，仍须完整回归、连续自然游玩、目标硬件性能及正式 HTTP/HTTPS 环境验收。

本轮应在实际 3D 预览检查大 V 领肩胸甲、象牙石纹 / 灰褐织物及各自 bump、肘膝褶皱、小腿和后脑结构；这些已替换进运行资产，但不声称与参考图 1:1 高精度一致。4 张 512 纹理一次生成，预算约 5.33 MiB；角色低于 45,000 三角形，最终 768 m 岩石分块只做视锥剔除，不按距离删除，世界几何 / 法线 / 碰撞保留一致。256 m 方案绘制 238 次，最终 768 m 为 161 次、基线为 138 次，测试需同时观察几何量和绘制提交数。

动态渲染比例范围 0.65–min(DPR,1.25)，含热身 / 迟滞，仅缩放 3D 画布，不改变 UI 或模拟。性能记录要同时记录视口、内部比例、真实 GL 驱动和帧耗时，不能只报 FPS；此前未记录真实驱动，不断言软件 / 硬件渲染。1440×900 无头采样 p50 / p95：基线 416.7 / 433.4 ms，中间 after 为 299.9 / 366.7 ms（未接岩石分块，不是最终收益），最终 tuned 为 383.3 / 483.3 ms。P95 反而恶化，结果波动，未证明实机流畅或稳定 60 FPS；追加 [verified](ui-implementation/locomotion-profile-verified.json) 记录 ANGLE Google Vulkan SwiftShader Device (Subzero) / SwiftShader driver，确认该次无头软件渲染；p50 / p95 / max 为 349.9 / 433.3 / 450 ms，比例 0.65，161 次绘制、379,840 三角形。不能事后声称旧基线使用相同驱动，也不能将本次原生渲染耗时主导推定为用户设备驱动问题；不承诺实机改善比例。保留 [基线](ui-implementation/locomotion-profile-before.json)、[中间版](ui-implementation/locomotion-profile-after.json)、[最终分块采样](ui-implementation/locomotion-profile-tuned.json) 及其他原始 profile。动画混合 6,000 次 Node 微基准 99.990→56.839 ms 也不是全游戏 FPS 增益。

## 查看结果、复现失败

每次生成独立目录：`playable/test-artifacts/<时间-进程号-玩法>/`（不提交到 Git）。

- `summary.json`：选择的测试、各阶段退出码、耗时、浏览器通过数量、测试前后 SHA-256 指纹和待人工验收项。
- `README.md`：本次简要结论。
- `build.log`、`rules.log`、`browser.log`：阶段日志。长测试运行时可直接打开查看进度。
- `html/index.html`：浏览器报告。可执行 `npx playwright show-report <报告目录>/html` 查看。
- `artifacts/`：失败截图、错误上下文和保留的 trace。可执行 `npx playwright show-trace <trace.zip路径>` 查看失败操作记录与 DOM 快照。为避免连续录屏拖慢实时动作测试，不采集逐帧影片；3D 失败现场使用独立截图。

规则或构建失败时停止后续阶段。浏览器测试禁用重试和 `test.only`；失败、跳过、预期失败、flaky、空测试或全局错误都不能把发布检查变绿。修改源代码、素材、运行包或测试后必须重测；运行中这些文件变化会导致汇总失败，不能用旧代码的报告给新版本背书。

## 结果不是“自动上线”

| 汇总状态 | 含义 |
| --- | --- |
| FAILED | 存在失败、缺少有效浏览器结果，或运行期间被测文件变化 |
| RULES_ONLY_NOT_RELEASE | 只验证规则，未验证浏览器玩法 |
| FEATURE_PASSED_NOT_RELEASE | 当前单项通过，不代表其他玩法通过 |
| AUTOMATION_PASSED_MANUAL_REVIEW_REQUIRED | 全部现有自动化通过，可以进入人工发布验收，不能跳过它 |

本工具不部署、不改变线上环境。当前仍有未实现的五境界成长、攻防战斗、专用闪避动作等设计，测试通过不会使未实现功能自动完成。

## 发布前必须补齐的检查

1. **当前版本完整回归**：运行 `npm run test:release`；保留报告、版本和产物指纹。失败项修复后重跑受影响单项，最终重新跑完整回归。
2. **贯穿流程**：新档完成调查→进舰→修复→黑匣子返回→第二章→所有远野归档；同时取得载具及成长。不把放置/进度夹具测试当成一次完整自然游玩。
3. **正式托管环境**：在拟发布的 HTTP/HTTPS 地址测试资源加载、刷新、首次启动、保存继续及旧档兼容。当前多数自动化验证的是 file:// 离线版。
4. **视觉/输入**：多角度检查船体和地形遮挡、角色动作、闪避/扫描特效；检查驾驶环视、鼠标捕获、中文按钮和常用分辨率，不以截图文件存在代替验收。
5. **性能/稳定性**：目标设备记录帧时间、峰值内存和长时间游玩表现；反复切菜单/扫描/闪避、进出舱室、飞行驾驶后没有持续内存增长。补充 WebGL 上下文丢失恢复检查。
6. **发行范围与授权**：明确本次发布是现有探索原型还是完整游戏；核对美术/动作素材许可、存档说明和已知限制。确认后再授权部署。
