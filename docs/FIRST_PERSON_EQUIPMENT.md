# 第一人称操作与扫描器 · 2026-09-12

当前第一人称默认空手。Q 才取出扫描器，完成读数后合拢传感翼并收回；E 为已解锁的矢量闪避，F 保持交互。肩灯安装在服装上，L 开关肩灯不会凭空拿出物品。目前真实可用的手持装备只有扫描器，未增加虚构的武器或物品切换菜单。

- 构建：`D:\blender\blender.exe --background --python tools/build-scanner-equipment.py`，随后 `node tools/pack-scanner.cjs`、`npm run build`。源文件保留取出/收起关键帧，GLB 导出展开姿态；运行时控制独立组，离线 bundle 内嵌资产。
- 本轮无 aholo 请求，aholo 积分支出为 0。

## 行为

取出 0.55 秒 → 使用 1.25 秒 → 合拢 0.30 秒 → 收回 0.50 秒。扫描波在取出结束时发出一次，持续 5 秒；设备收回后波仍继续传播。冷却 8 秒，连续按 Q 不重复创建模型。闪避会从当前取出位置收回设备；若尚未发射则取消本次波。暂停冻结动作。继续存档时回到空手，不恢复半截持物状态。

第一、第三人称共用观察方向计算；第一人称实际镜头同时跟随水平、俯仰输入，Alt 环视独立于身体，松开平滑回正。无鼠标锁的嵌入浏览器支持按住左键拖动，并用屏幕坐标差补足缺失的相对鼠标位移。第一人称持物动作只作用于手部，不摇晃地平线。

Z 在地面切换趴下/站起，支持按住 Ctrl 慢走时操作。起伏地面的身体支撑不会被误判为墙；仍检查固体障碍、边界与站起净空，空中和驾驶时不可趴下。Space 轻按跳跃，按住至少 0.30 秒转助推；G 保留直接助推。松开缓降，限高、耗能、舰内禁飞仍有效。低姿态起跳/助推会先尝试起身，净空不足时不会穿顶。
