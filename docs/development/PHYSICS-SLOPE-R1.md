# PHYSICS-SLOPE-R1 — 三维坡面接触与性能修复

2026-09-16，基于 PLANET-MVP-R1。保留原地图、人物、载具、紫色天空、调查与存档；本次修正物理和渲染，不更换美术资产。

## 已接入

- 原盆地与远端球面车辆使用九点足迹支撑；车身和骑手按坡面法线倾斜。上坡按行进方向限制坡度，下坡允许通行，离开支撑后重力下落，落地约束防止穿地。
- 陡坡滑动速度与驱动速度分开，时间步响应不再积累成帧率相关加速。空中禁止下车，上下车清除残留驱动速度。
- 人物离开地面进入重力下落，限制不可行走的上坡方向。野怪导航坡度按实际路程计算；攻击使用真实三维距离及高度差，保留玩家实际高度。
- 原盆地和球面车辆保存下落状态；远端 world.sampleVehicle 按完整足迹验证支撑，旧中心点停车档仅在原接地验证成立时迁移，拒绝任意地下位置。球面低空追尾相机做地形短臂碰撞。
- 原地形精确分成 144 块供视锥剔除：保留全部 720000 三角形、颜色、UV、原法线，不简化山体。远端视角跳过无效的盆地相机碰撞计算。

## 复测步骤

1. 正常入口刷新后继续原存档，在坡面驾驶：下坡应连续降低，上坡过陡应阻挡，车身随地形倾斜。
2. 驶出断崖后应持续下落并落地；空中按F不可下车，保存恢复不得瞬移到谷底。
3. 停车F下车，再上车不踩油门应无残留驱动；V切换视角，检查山体旁追尾镜头。
4. 跳起/飞到野怪上方或隔开高差，攻击不能仅按水平距离命中。
5. 隔离画面复测：/?test=1&physicsFixture=vehicle-slope 或 vehicle-steep；测试页不写正式存档。
