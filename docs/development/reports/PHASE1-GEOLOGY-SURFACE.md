# Phase 1 geology surface

Reference: `docs/art/environments/phase1-v1/map-concept.png` was inspected before implementation. The surface follows its dark basalt, irregular horizontal bedding, fractured exposed slopes and granular dust.

New module: `playable/src/phase1-geology.mjs`. Import `enhanceTerrainMaterial` and call `enhanceTerrainMaterial(ground.material)` immediately after creating the ground mesh, before rendering. The method returns the same material and is idempotent. It preserves existing material hooks, textures, vertex colours, standard Three lighting and shadows. Static, uniformly scaled rock materials can also use it. Do not use for animated/skinned meshes.

World-space 3D noise avoids stretched cliff UVs. Slope-dependent strata and interrupted fracture lines alter colour and lit normals. Fine grain fades with pixel size to reduce distance shimmer. There is no geometric displacement, new collider, extra draw call or runtime update. Terrain silhouettes still come from the shared height function; this material cannot replace actual ridges and craters.

Controller visual feedback caught an artificial masonry pattern in the initial crossing periodic fractures. The final version removes those periodic fracture lines entirely: fractures follow interrupted 3D noise level sets, bedding is locally distorted and its groove depth/contrast reduced. The updated isolated screenshot was inspected and WebGL test rerun after the correction.

R3 adds the controller-generated `playable/assets/environments/phase1/basalt-albedo.png`, inspected before use. A single shared TextureLoader loads one optional SRGBColorSpace texture; successful decoding enables a shared uniform, while failed loading leaves procedural shading active. World-coordinate triplanar sampling uses fourth-power normal weights, repeat wrapping, mipmaps and anisotropy 4. Slope masking leaves level dust mostly unchanged; image detail decreases from 45 to 190 m. Colour modulation is bounded to avoid black surfaces. `enhanceTerrainMaterial(material, {basaltTexture:false})` disables the image; `textureUrl` can override its source for an isolated application. Do not individually dispose the shared image during scene changes. Outcrop colour bedding was reduced to 0.98–1.01 instead of obvious coloured rings; no geometry was changed.

The updated WebGL test serves the real PNG, waits for image load and renders the triplanar path: PASS, textureLoaded true, no shader/JS errors, one draw call. Screenshot was inspected but remains an isolated surface check; native full-map quality is still controller-owned.

Validation: run `node playable/tests/phase1-geology-webgl.cjs`. Headless Chromium creates a real WebGL renderer and renders a 220-segment relief test mesh with original-style moon illumination, mapped/vertex-coloured MeshStandardMaterial. PASS: no JavaScript or shader compile errors, one draw call, repeated enhancement returns the same object. Screenshot: `artifacts/tests/phase1-geology/terrain-surface.png`; machine result: adjacent `result.json`. This is an isolated shader test, not an assertion that full game integration or performance has passed.
