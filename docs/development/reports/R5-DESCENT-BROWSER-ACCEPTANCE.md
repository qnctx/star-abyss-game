# R5 元婴 C 下降独立浏览器验收

测试使用独立 Playwright Chromium、1440×900、DPR 1.5。每次 F2 跳转高度后，先实际点击“恢复键盘飞行”，再按住真实键盘 C；第三人称通过 V 切换。没有修改游戏状态或位置来完成下降。每 0.5 秒记录玩家脚高、HUD 取整离地高度、竖直速度、飞行状态和渲染倍率，另采集 rAF 帧时与 longtask。`terrain.pending` 未由公开测试快照暴露，报告保留 `null`，没有将其解释为无待处理地形。

三包所有要求的 30 米和 200 米下降均真实落地，脚高与 HUD 离地高度单调下降，没有向上位置阶跃。首次脚本曾把下降差值误计为“upwardSteps”；[基线原始样本](../../../artifacts/r5-baseline/report.json)已据真实记录修正。截图显示第三人称角色、地表与落地后的营地视野正常。2000 米只做约 12 秒下降采样，不宣称该高度完成落地；候选松开 C 后竖直速度回到 0 并保持飞行悬停。

下降速度明显加快，但 200 米段的慢帧比例没有随之改善。独立 [CDP 诊断](../../../artifacts/r5-profile/report.json) 在候选 200 米下降时记录主回调 CPU p95 约 6.9ms、rAF p95 33.4ms；多数慢帧发生在离地约 200～56 米的前 5 秒，最后约 33～4 米的 3 秒未见 >33.34ms 帧。115／71／53ms 的孤立 longtask 仍存在，不能据此单独认定 GPU 是唯一原因。

[像素预算对照](../../../artifacts/r5-ratio-diagnostic/report.json)只用 QA 页面路由将渲染预算上限从 1.25 改为 1.0，生产文件未变。实际倍率从 1.0 自适应降至 0.95；200 米慢帧降至 12/485（2.47%，1.38 帧/秒），但 p95 仍 33.2ms，说明降低像素压力有帮助而未消除所有慢帧。自适应试验候选 200 米在离地 200～55 米期间始终为 1.25，约 43 米才降至 1.15，与其前段慢帧仍在的结果一致。最终源码候选直接将上限设为 1.0，在本次 200 米全程样本里实际倍率始终为 1.0；7/465 慢帧及 p95 16.8ms 是同包真实浏览器结果，仍保留少量孤立慢帧，不能保证所有设备恒定 60 FPS。

复验命令：先启动对应构建的静态服务，再运行 `node artifacts/r5-browser-baseline.cjs`（4173 基线）或 `node artifacts/r5-browser-baseline.cjs --r5c`（4180 最终候选）；CPU 诊断单独运行 `node artifacts/r5-descent-profile.cjs`。rAF 测量包含每 0.5 秒快照与两张截图，CDP 运行不用于与无 profile 帧时直接比较。四轮正式与候选验收报告均 `complete=true` 且无页面错误；最终候选截图已人工核对第三人称角色、地表、落地视野与中文 HUD。
