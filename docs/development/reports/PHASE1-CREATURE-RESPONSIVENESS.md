# 第一阶段：掠兽反应与公平追击

日期：2026-09-16。开发定向验证完成；地图联合实机效果由中控/独立验收核验。

## 实现范围

- `playable/src/expedition-runtime/index.mjs`：接入新 AI、攻击启动授权、攻击时模型与提交方向一致、按实际移动标记动画。
- `playable/src/expedition-runtime/creature-ai.mjs`：瞬时导航/感知记忆，不添加存档字段。
- `playable/tests/creature-ai.test.mjs`：9 项确定性行为测试。

原实现对直线路径也缓存 1.5 秒且目标位移超过 4 米才提前更新，近身转身不灵活；离出生点即标记 chase 会导致停住也踏步。

现在无遮挡目标每帧更新，朝向以 5.5 rad/s 有限旋转，急转时减速；有遮挡时沿原有有界 A* 路线绕行，每段仍检查 canTraverse 和 dynamicBlocked。保留有效路线，避免频繁重建相对网格导致来回走；目标变化后的重规划间隔为 0.55 秒。

可见目标在原 35 米感知范围内引起追击，6 米以内按近距听觉反应，受伤也会警觉。丢失视线后向最后观察位置搜索 3 秒，然后返回原领地。玩家在安全营地或离开原领地后立即停止追击。该记忆仅存在当前运行期，读档不会新增或改变 scene schema。

攻击启动必须满足距离、朝向与视线；已提交攻击继续使用原 0.85 秒前摇和 1.1 秒恢复，不追踪修改已锁定方向，玩家仍可横移躲避。攻击提交时模型面向与命中判定方向一致。停住超过 0.12 秒后不再循环追击动画，保持正式 GLB 既有动画协议。

## 定向验证

在主项目目录执行：

```cmd
node --test playable/tests/creature-ai.test.mjs
node --test playable/tests/d3-combat.test.js playable/tests/d3-session.test.js
```

结果：AI 9/9，原战斗/事务存档回归 37/37。AI 验证直线横移即时更新、遮挡不远程透视、最后位置记忆与遗忘、近距/受伤感知、安全边界、最短角转向、攻击启动门槛、移动障碍解除、岩石绕行各段不穿透、停步不持续 chase。首次岩石绕行用例暴露频繁重建网格的停滞，修复保留有效路线后通过。

测试为确定性业务/几何夹具，不代替真实输入下的完整游戏验收。建议实机在营地东侧掠兽处横移、绕一块岩石、等待其接近后在前摇中侧移，再回营地；核对追击转身、攻击能躲、停住不踏步，以及 R 击杀/H 拾取/刷新存档。

## 边界与后续

- 原 `busy` 事务期间暂停模拟仍保留：其保证已提交 scene 快照不会覆盖异步过程中新的位移。慢磁盘或存储异常仍可能引起短暂停顿，未经专门事务设计不并行修改模拟。
- 6 米听觉允许隔石警觉，但攻击仍必须视线畅通；失去視线后的搜索为最后位置停留，不是全导航网格探索。
- 保留原 A* 范围/节点预算、单敌攻击与原 GLB 动画；无群体包围、跳跃攀爬、额外动画或新增收费资产。
- 未修改 main、渲染、地图、地形、存档 schema、伤害数值、掉落规则；未重建主 bundle，交中控联合构建。
