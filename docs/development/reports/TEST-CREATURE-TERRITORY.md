# 掠兽自主巡游与领地行为

日期：2026-09-16。修改现有 AI 与导航，不新增或替换美术资产。

## 行为闭环

- 没有玩家入侵时，掠兽在巢穴周围自行选择巡游点，以追击速度的 42% 移动；到达后警戒 0.7–2 秒并缓慢转头，再继续换点。
- 路线由巢穴位置与巡游序号确定，同一输入可重现，不使用每帧随机抽样。巡游目标在领地半径的 14–42% 以内，避免直接走到领地边缘。
- 既有视线、近距离声音、受击察觉立即打断巡游；检测通过后追击，遮挡后最多保留 3 秒最后位置记忆。
- 玩家离开领地、进入营地或目标丢失后，掠兽以 70% 追击速度回巢，再恢复警戒与巡游。返巢途中不会被来回拉扯重新捕获目标。
- 驾驶等禁用玩家近战状态仍允许掠兽自主活动。菜单暂停仍由现有 runtime 控制。
- 每一移动段继续经过共享地形/碰撞导航、安全区与领地边界检查；受阻后重新选点，不瞬移，不穿墙。局部路径搜索限制重试频率。

`memory.behavior` 与返回值 `behavior` 提供 `watch / patrol / chase / return`。`memory.lastMoved` 保持兼容现有动画。AI 记忆仅为临时导航状态，既有存档结构不变。
