# TEST-LAB-R1 — 元婴测试实验室、驾驶对位与性能修复

基于 SUPPORT-TERRITORY-R1，整合三个隔离任务；正式入口与独立测试入口共用修复后的渲染/物理实现，存档分离。

## 使用

- 测试入口：`http://127.0.0.1:4173/test-lab.html`，自动进入元婴测试档。F2打开/收起实验室。
- R4元婴一级使用真实战斗数值：生命155520、攻击15552、真气1600；高空/轨道属于额外测试权限。
- 面板提供13处地理/外勤入口、导航、30米至120公里观景高度、停悬/升空/下降、飞行速率、安全落地/返营、驾驶、战斗、采集和背包入口。
- 观景跳转默认停悬；要自由飞行，点“恢复键盘飞行”，G升空、WASD航向。驾驶F上下车、V切视角；R攻击、H采集、I背包。
- 正式入口仍为 `http://127.0.0.1:4173/`。实验室使用独立localStorage key和IndexedDB，重置仅清测试档。
- 目前有出生星各生境真实3D与盆地四个外勤区；远方战斗、其他星球、宗门、御剑和宠物等尚未接入，面板已注明。

## 修复

驾驶双视角共享车辆座位/把手/眼位坐标与同一原GLB角色骨骼；删除独立假手臂，骑乘手掌对准真实把手，坡面及球背最终变换后统一对位。头部隐藏按视角复位，下车/趴伏/装备扫描不残留掩码。车辆与趴伏导出资源及源SHA清单同步更新。

动态画质下限从0.65提高到0.90，并加入抗抖和CPU耗时判断，避免CPU卡顿反复降低画面分辨率。地形构建按小片泵送，保留旧完整网格直到新集可替换；不简化几何。野怪碰撞只去重位置/蒙皮完全相同的接缝顶点。检查点继续使用原事务/CAS/回执语义，在独立Worker中处理，失败按原流程恢复。

## 验证

- 最终完整自动回归：395项JS +167项MJS，全部通过；构建通过。
- 测试版独立浏览器46项检查通过；驾驶坡面/球背双视角与转向、头部掩码复位通过。
- 主控联合浏览器8项通过：真实R4、真实资源生成、Worker启动、面板无横向裁切、刷新同root、重置重建Worker与新R4、正式localStorage/IndexedDB哨兵不变、page errors=0。证据 `artifacts/lab-worker-browser.json`。
- 主控实际应用浏览器：通过面板前往河谷森林，显示真实树木、离地30米；前往车辆后实际F上车/V切换双视角正常，控制台错误0。
- 实際应用驾驶静止场景，670×793窗口、像素比1.25，180帧：平均16.666ms、P95 16.8ms、P99 16.9ms、最大17ms，>33ms为0。此数据仅代表该场景与窗口，不保证所有硬件/地图帧率。
- 同窗口营地连续自动行进，从Z190到Z104，采样180帧平均16.666ms、P95 16.8ms、最大17ms、>33ms为0，像素比保持1.25；结束时打开实验室暂停角色。
- 性能专项同路线地形工作分片P95由233.67ms降至3.48ms，总CPU相近；真实Worker+IndexedDB基准RAF P99由49.9ms降至16.8ms。显式远距离传送仍需同步准备地形，会短暂等待；面板提供准备提示。

## 复测

1. 打开测试入口，确认R4数值；F2选择森林/湿地/海岸/海洋等并前往，检查3D场景。
2. 选择200米或120公里，测试停悬、升空、下降与返营；深海不可强制落地。
3. 前往勘探车，F上车，V切换，观察手掌、座位和仪表对应；坡面重复检查。
4. 前往采集点H采集，I查看背包；刷新应保留测试角色与物品。重置只清测试档。
5. 返回正式入口继续原档，确认原调查进度未改变。
