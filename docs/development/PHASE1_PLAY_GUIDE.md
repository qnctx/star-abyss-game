# 第一阶段试玩：岩谷与追猎

入口：http://127.0.0.1:4173/ 。服务关闭时双击项目根目录的“启动试玩.cmd”。更新后刷新一次，保留旧存档，点击“继续调查”；菜单更新标记为“裂环盆地 · 岩谷与追猎”。正式更新时间以 HANDOFF 最新记录为准。

## 第一章路线

1. 从返回信标出发，沿岩谷前往约520米外的求救信号。WASD移动，鼠标转向；不能捕获鼠标时按住左键拖动。`=`切换自动前进，再按一次停止；M看地图，Esc暂停。
2. 靠近信号按F调查，再跟目标进入船体破口。先去左侧货舱取备用电芯，再恢复应急供电。
3. 在右侧中继室读值班员记录，按记录线索操作三台终端。输错可以重新尝试，已保存的进度可刷新继续。
4. 密封门开启后进入内层取黑匣子，沿原路返回营地信标按F交付。完成的是第一章调查；之后的地下回声任务属于后续章节。

## 近郊外勤支路

营地东北侧有资源和掠兽遭遇。R发动近距脉冲，观察敌人转身和扑击前摇，移动躲开后再还击。H采集/拾取，I打开背包；在营地储物点可存取。V切换第一/第三人称。F另用于原载具修复和上下车。

掠兽会依据视线、近距听觉和受伤作出反应，丢失目标后短暂追向最后看见的位置再回巢。岩壁可以挡住视线和攻击，但不是每个斜坡都能让怪物通过。物资、掉落与调查自动保存；不要通过清除浏览器数据修复加载问题。
