# R9 飞行姿态与空中拳脚

## 行为与入口

本片保留原六公里盆地、原 C2 角色、紫色天空、载具、调查和存档。常规飞行沿用直立悬浮；Shift 加速时，骨盆带动全身约 80° 前倾，双臂后收、双腿向后伸直、头部保持前视。切入/退出加速和侧倾均连续混合。高速侧转改为独立速度标量与限角转向，避免 A/D 切换先掉速再提速；碰撞或地形未加载仍会安全停止。

G 是唯一自身飞行键；Space 仍只用于地面跳跃与车上刹车。WASD 航向，Shift 加速，C 下降。R 保留 R8 的境界气刃/破虚，Y/Shift+Y 保留瞬移。新增 N 单次拳脚出招、按住 O 正面格挡；K 原战技面板不变。出招、格挡、受击期间不能加速移动；视角仍可转动。

N 有一槽、250 毫秒输入缓冲：存档提交时或近战最后 0.2 秒收招时可提前按一次，不会自动打完整串。菜单、离区、受击、格挡和救援清除缓冲。近战命中与对手未结算招式的打断在同一事务保存；硬直或格挡期间 R、主动战技、瞬移不能绕过限制。

实机发现原飞行速度不适合近身追击：W 约 0.16 秒可能越过 1.3 米外的目标。因此活着的敌人三维距离小于 8 米时，普通 WASD 自动使用最高 5 米/秒、30 米/秒² 的精细移动；Shift 明确退出精细移动以脱离，Ctrl 可在任意空域主动精细飞行。静止起步 W 0.2 秒约前进 0.6 米，仍沿原扫掠路径验证。

正式高阶角色可对盆地真实敌人使用近战。为了验证多轮人形空战，`?testLab=1&arena=1` 使用额外独立的 localStorage 和 IndexedDB，世界前缀 `test-lab:arena:`。F2 →「准备人形空战陪练」通过原有 director/materialize 创建真实角色属性与 CAS 伤害，并用原 C2 蒙皮角色显示。陪练会追近、对齐高度、前摇出拳、格挡与受击；不改普通掠兽或普通测试档数值。

## 动作与碰撞

先生成八格动作参考图，再在 Blender 中制作 hover、boost、left-jab、right-cross、rising-kick、air-guard、impact、launch。运行时沿用原角色的 native retarget，动作可在 `.blend` 中编辑，导出 19 骨局部四元数。近战接触时刻对应动画归一化 0.45；骨骼动画使用战斗模拟时钟，菜单暂停不会继续播放判定。侧移镜头偏置帮助看清近身两人，并平滑进入退出。

玩家击退收到的 dx/dy/dz 是总位移米数，按 0.55 秒指数曲线精确积分；每一步转换为当前球面切平面并检查实际地形与全段扫掠。被墙阻挡立即终止，不扣飞行灵息。相同事件 ID 不重复施加。暂停冻结、恢复继续；reset/rescue 清除残留反冲。敌人位移由战斗场景持久计划按同一时长推进，伤害由权威 CAS 提交成功后发生。

详细连段、格挡/弹反/破防和保存边界见 `AERIAL-MELEE-R9.md`；转向测试见 `FLIGHT-STEERING-R9.md`；美术源文件与渲染校验见 `docs/art/air-combat-r9/`。

## 人工测试步骤

1. 打开 `http://127.0.0.1:4173/star-abyss.html?testLab=1&realm=4&arena=1`，F2 → 准备人形空战陪练 → 收起并游玩，V 切第三人称。
2. 面向陪练，逐次按 N 衔接左拳、右拳、上挑踢；看手脚动作、敌人生命减少、受击硬直与连续位移。距离不足或朝向不对会落空。
3. 对手前摇时按住 O：正面架挡，临近命中的新按键可弹反；持续承受格挡会破防。松 O、F2 打开菜单或切走窗口后不能残留格挡。
4. F2 选 1,600 米 → 前往该高度 → 恢复键盘飞行。分别 W 与 Shift+W：前者直立，后者全身俯身；保持 Shift+W 交替 A/D，观察航速和侧倾连续。
5. 松 Shift 恢复直立，C 降落；确认 Space 不再触发飞行，G 可起飞。炼虚档复核 Y/Shift+Y 瞬移及 R 旧气术。

## 范围

这是已接入的空中近战基础回路，不代表完整格斗游戏：目前没有抓投、布娃娃物理、武器对刀、多人网络或任意方向受击动作库。原有远区战斗和完整高阶自然突破链仍未开放。不得以 CPU 动作/转向测试代替实机帧率结论；最终浏览器证据和发布哈希以 `artifacts/r9-candidate/report.json`、`artifacts/r9-published-verification.json` 为准。

## 候选实测

候选 bundle SHA256：`e7685e07918aaf89394d56f5fdb31566d4f86e17b45262f2efe6705b3cfd0658`。15 个相关测试文件共 113 项 CPU 测试通过；美术另有 808 个姿态采样检查。

独立浏览器使用真实按键与原 CAS：左拳、右拳、踢击分别使陪练 HP 从 1244160 降至 1231719、1219278、1196884；第三击记录 launch，陪练脚点从 33.80 米升至 36.07 米并向后位移。两次正常追击 W 按住 0.20/0.25 秒，前进约 0.54/0.71 米，没有穿过对手。真实 O 连挡两次、第三次破防；松键、菜单与重新载入可解除格挡。失败尝试保留在 artifacts 中，最终是否全部通过以同 hash 的候选报告为准。

最终同包浏览器报告 complete=true，12 项断言全部通过，页面与游戏运行错误均为空。真实按住 G 180 毫秒可升空，Space 地面跳跃且空中不会重复起飞。高空 W / Shift+W 各 2 秒实际位移约 338.27 / 604.92 米；加速 A/D 侧倾连续变向。该次短轨迹 142 帧的 p95 和最大帧间隔均约 16.8 毫秒，不能据此保证所有场景帧率。第三人称出踢瞬间、常规飞行和俯身加速截图已人工核对。精准弹反由 CPU 规则测试覆盖，本次浏览器未验证精准弹反时机。
