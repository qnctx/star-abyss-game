# R10 空战鼠标操作与动作衔接

## 操作与连段

持续侧转回正的原因是旧侧倾只取「目标航向与当前速度方向的误差」；航向追上目标后，即使 A/D 仍按住，该误差也变为零。R10 在加速时加入持续侧向输入的稳态侧倾，再叠加较小的转弯响应；松侧向键、退出加速时渐变归正，左右反向也经过插值。零时长物理更新不再清除 boosting。飞行动画与原姿态资产不替换。

飞行中鼠标左键单次拳脚攻击，右键按住正面格挡；N/O 仍可作为兼容键。地面交互、G 起飞、Space 跳跃/车刹、R 气术和原境界瞬移保持原规则。

鼠标已锁定时，左键按下出招。首次捕获镜头的点击不攻击；浏览器不支持或拒绝指针锁定时，短按并松开左键出招，拖动仍只转镜头。右键与 O 各自持有格挡，只有全部松开才解除；菜单、失焦和暂停统一解除。输入监听仅在游戏画布上接收鼠标出招，UI 按钮与对话不穿透。

每一招有一个后续输入槽：可以在前摇、收招，甚至当前起手/命中 CAS 提交期间提前点击下一招。槽按当前招式结束时间保留，最多一秒；普通存档忙时仍只保留 250 毫秒。每次点击最多预约一招，长按不会自动打完整串，起手 CAS 失败不会把预约变成意外攻击。连段接续窗口为 1.35 秒，第三击结束回到左拳；受击、格挡、菜单、救援仍清空预约。

动画沿用 R9 图像参考制作的原 C2 骨骼动作。收拳与下一次出拳之间混合已有格挡动作的手臂姿态，保留短暂准备势，避免双臂先完全垂下再抬起。准备势只有视觉作用，不提供格挡。接触仍对应原动作 0.45 的完整伸展，伤害、攻击范围与硬直时长不因动画混合改变。

## 人工测试

1. 打开 `http://127.0.0.1:4173/star-abyss.html?testLab=1&realm=4&arena=1`，F2 → 准备人形空战陪练 → 收起并游玩，V 第三人称。
2. 点击画布捕获镜头后逐次左键，第二次可提前点：观察左拳→右拳→踢击、生命下降与击飞。停点后不得自动继续攻击；需要贴近或微移追击，超出范围仍落空。
3. 右键按住格挡，松开解除；同时按 O 后松右键应保持格挡，松 O 才解除。打开菜单、点击菜单按钮不能出拳；关闭菜单、切换窗口后不应残留格挡。
4. 未捕获鼠标时拖动画布只能转镜头，不得误攻击；浏览器拒绝捕获时短按左键仍能攻击。
5. 高空分别测试 Shift+A、Shift+D、Shift+W+A/D 连续保持与交替，再松 Shift，观察加速前倾与侧倾是否连续。
