# R11 裂翼巡猎兽：同一角色的地空战斗

## 资产与行为

新种类沿用已交付裂隙兽的原石甲身体，依据本轮生成概念图添加可收展膜翼。概念在 `docs/art/creatures/riftwing-r11/concept.png`，可编辑 `.blend` 和游戏 `.glb` 在 `playable/assets/creatures/riftwing-r11/`，构建、材质、动作与包络数据见该目录 manifest 和美术 DELIVERY。没有替换原掠兽，也没有重新调用付费 Lux3D。

同一个 `riftwing-hunter` director 成员保留生命、仇恨、受击、掉落与保存状态。地面爪扑；玩家升空后展翼追击、俯冲/横扫；玩家落地后收翼追降。前摇期间可移动或格挡，命中和伤害通过原 CAS。死亡后不可通过测试按钮再次生成战利品。演员属性按正式 R4 基础属性生成：生命 311,040（标准 R4 玩家两倍）、攻击 6,221（40%）、防御 12,960；测试档也使用真实境界属性，故 R4 不会一拳秒杀这只怪物。既有存档的演员属性保持原值，不会迁移覆盖。

鼠标左键三段拳脚和右键格挡扩展到步行状态，N/O 兼容。地面玩家受击使用总位移米数的 0.55 秒缓动，走原地面路径/坡度碰撞，遇障碍停止；空中仍走原球面扫掠。新怪物动画由场景模拟时钟驱动，暂停不继续拍翼或出招。模型加载失败阻止玩法启动，重试通过后才允许战斗，避免 invisible actor。

碰撞基于真实模型采样包络：地面半径 2.16 米，飞行 2.97 米，展开/收拢过渡 3.46 米，高度 2.85 米。短步运动检查原地形、建筑、道具、车辆与营地；地面足点逐步贴合目标地形高度，展开翼先通过体积扫掠才允许抬升。起飞至少播放 1.2 秒、落地至少播放 1.3 秒；视图给出保存的 `modeSince`、攻击 `start/contact/end`，动画由模拟时间决定。战斗仍限原盆地，空域遵守 2,000 米边界与脱战范围，不承诺全行星怪物追踪。

## 试玩步骤

美术实测行走步幅约 1.28 米/周期（1.1 秒）；地面追击速度定为 3.4 米/秒，按实际位移速度 / 1.16 调整步频、最高三倍，避免原 6.8 米/秒用慢步态滑行。空中追击与俯冲保持独立速度。

地面与空中都根据状态栏实际高度排布任务文字；怪物蓄势、受击、死亡造成状态栏换行时，任务栏保持至少 12 像素间距。地面接战和击杀后分别验证，防止仅空中布局正常。

1. 打开 `http://127.0.0.1:4173/star-abyss.html?testLab=1&realm=4&arena=1`。F2 → 前往裂翼巡猎兽 → 收起并游玩；V 切第三人称。
2. 靠近观察四足追击和爪扑前摇；左键拳脚、右键格挡。被打退后用 WASD 重新贴近，超出攻击距离会落空。
3. 按 G 升空，松开后悬停，观察同一只怪物展翼、升高、追击。保持低空先测，Shift 加速可以脱离追击。
4. 空中攻击/格挡，观察双方真实生命变化与受击动作；按 C 下降，观察怪物收翼落地，继续地面交战。
5. 击杀后落地靠近按 H 拾取，I 核对物资。刷新同档，确认怪物不复活、已拾取物资不重复生成。
6. 在坡地、建筑附近观察展开翼及身体是否穿透，菜单暂停/恢复、切换视角后不得出现模型丢失或点击误攻击。
