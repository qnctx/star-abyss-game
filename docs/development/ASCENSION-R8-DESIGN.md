# R8 六境御空与空间战技

状态：实现、CPU 与独立浏览器候选验收完成。正式运行版本以发布校验记录为准。

## 能量与瞬移

加速额外消耗飞行灵息 1.5 个百分点/模拟秒；不足 10% 时回到常规飞行。悬停按 Shift 不加速、不产生额外消耗。HUD 与气流取自权威 `state.boosting`。

炼虚开始 Y 短虚步、Shift+Y 长距预览确认；短距消耗灵息 12%、长距 25%，共用冷却。空战消耗角色真气，两个资源账本分开。冷却按模拟时钟计算，地面继续、菜单暂停，存读档保留。

虚步逐段采用真实球面坐标推进，核验已加载地表、障碍、水与离地上限。长距确认再次核验起点、路径、境界、能量、冷却与序列；过期或重复票据拒绝，失败不扣费。当前不会把未加载地形视为空地，失败时应换方向或先飞近。完成后清除旧速度，起落点分别显示空间门。

## 空战与范围

真实全局飞行位置转为盆地局部坐标参与战斗，禁止用停放位置命中。只有已加载六公里盆地开放空战；1/2/3 仍须真正学习与装备。掠兽保留原地面实体，1.15 s 锁定预警后远程反击；红色气刃显示方向，移动能躲避。命中、死亡、遗留物、落地 H 拾取和库存经过原 CAS 流程。越区取消未完成前摇，不补发伤害、已扣真气不退。详见 [空战实现](ASCENSION-FLIGHT-COMBAT-R8.md)。

破虚是局部空间攻击与界门效果。永久地形破坏、跨星跃迁、完整高阶成长任务未实现，不以视觉门户冒充真实目的地。正式突破链仍以早期内容为主，高阶能力通过独立测试档验证。

## 测试步骤

1. `star-abyss.html?testLab=1`，F2 选择元婴至道源；每个 realm 独立 localStorage/IndexedDB，普通入口不读测试档。
2. F2 前往 1,600 m，再点“恢复键盘飞行”；W 到常规速度，追加 Shift 比较加速 HUD 与第三人称气流。近地限速为正常规则。
3. `?testLab=1&realm=6` 升空 Y 移动 12 m，冷却结束 Shift+Y 预览 60 m；取消不收费，确认只收费一次；刷新保留能量和冷却。
4. F2“前往空战点”，收起后 R。已经悬停瞄准真实活掠兽；WASD 躲反击，C 落地后靠近遗留物 H 拾取。
5. `realm=8`、`realm=9` 比较破虚前摇、范围和模型；1/2/3 未学习不发技能；F2 重置只删当前境界档。
6. 地面长按 Space 只跳一次；车上仍刹车；V 检查第一/第三人称无遮挡。

CPU：关联逻辑、真实 GLB 加载/特效时序、盆地边缘瞄准及球面适配定向累计 74/74；空战代理五组独立回归 59/59。旧球面适配测试已按现有 C 下降/松键悬停契约修正，不再期待松键自动落地。最终游戏 SHA256：`7427160201567fbbc47f53b70dc9b44c93580b73e41c88136a83c2b913e78c0b`。

实机接线验收要求：飞行分支必须继续调用真实外勤 `tick(dt)`；不能只检查施法按钮、模型 ready 或 pending。首轮发现遗漏后已修正，最终需同时断言 simTime 推进、目标 HP 减少、死亡遗留物生成。蓄力与视觉用 `combat.time`，菜单暂停不应让视觉提前命中。

## 浏览器验收与发布

同包独立 Chromium 实测：常规 W 2 s 位移约 338 m、Shift+W 约 615 m，第三人称角色与气流可见；炼虚短虚步 12 m、长虚步 60 m，扣费及重载冷却保持。星劫/道源各一次 R 将真实目标 HP 96→0并生成遗留物；掠兽反击实际扣血。星劫 C 下降约 2.18 s 落地，W 靠近，H 将遗留物 2→1、背包新增血液 1；重载两者保留。

六个图鉴模型均可加载，GLB 与 Blender 源文件均 HTTP 200；390 px 窄屏无横溢。并未声称完成全部境界/技能槽/跨区场景的实机穷举；这些的定向 CPU 检查及未测范围见总报告。
