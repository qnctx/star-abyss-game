# 原游戏整合版试玩

若提示 ERR_CONNECTION_REFUSED，双击项目根目录的“启动试玩.cmd”，或在项目目录运行 `node tools/start-playtest.cjs`，再刷新页面。启动器让本地服务独立后台运行，不依赖临时测试终端；电脑重启后需重新启动。验证步骤：运行启动器看到 Game ready，再打开4173入口确认标题和开始/继续按钮。

入口：[本机试玩](http://127.0.0.1:4173/)。本版在原6×6公里月面接入外勤玩法，保留原角色、星空、调查与载具。图二独立白盒已归档退出入口。

## 操作

- 开始/继续调查，WASD移动，鼠标转向；无法捕获鼠标时按住左键拖动。V切第一/第三人称，M地图，Esc暂停。
- 出生营地约X0、Z190。向东北走至X80、Z100附近有矿簇与掠兽；注意绕开岩石。
- 靠近敌人并面向它，R近距脉冲攻击；靠近矿点或掉落，H采集/拾取。
- I打开背包。在出生营地附近可逐份存入/取出；开包暂停战斗。超重会拒绝采集或取仓，先存放再返回采集。
- 被击倒后选择营地救援，已取得物品和敌人伤势保留；刷新可继续。
- T追踪原勘探车，F回收部件/修车/上下车。原调查按屏幕任务与F交互继续。

## 已验证与限制

独立测试通过采集耗尽与重复操作、战斗唯一掉落、携物死亡救援和读档、背包焦点暂停、自然代际，以及超重拒绝→营地存放→同一矿源恢复采集→再次拒绝。车辆动态阻挡经过独立几何与真实runtime消费者测试。

实际隔车攻击/追击和持续驾驶未完成有效实操验证；完整旧故事与全部远点未在本轮重走。负重连续移速/体力倍率尚未接入。业务拒绝当前可能同时显示“保存失败”和携重上限说明，测试确认拒绝时完整根未变，不能据该文字推断存储故障。
