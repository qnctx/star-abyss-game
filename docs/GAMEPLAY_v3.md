# 星渊迷航 — 玩法设计 v3（GLM 开发执行版）

> 目标：把当前已经实现的系统收束成一个更清晰、更可落地的 MVP，而不是推倒重写。  
> 本文档用于指导下一阶段开发；若与远期 GDD 冲突，以本文档为准。  
> 重要原则：保留已跑通的信号台、撤离坚守、扫描器、地下资源、死亡掉落、工具栏和建造防守系统。

---

## 0. v3 Review 结论

上一版 v3 的方向是“精简”，但有几处会让开发变成大重写，不适合作为 GLM 的直接开发稿：

| 原设计 | 问题 | v3 修订 |
|--------|------|---------|
| 主线改成“收集 5 个飞船零件，建造逃生飞船” | 当前已实现的是 Signal Beacon → Radio Log/Cache → Extraction Holdout，改主线会废掉大量现有代码 | 保留信号/撤离主线；把“飞船零件”改成叙事层面的 Signal Cache/撤离坐标奖励 |
| 砍掉扫描器/地下资源 | 当前扫描器、地下资源、工具栏已经形成探索闭环 | 保留，并作为白天探索的核心玩法 |
| 砍掉信号台/撤离坚守 | 这是当前最完整的终局闭环 | 保留，优先修节奏和读档边界 |
| 背包格子制 + 基地仓库 | 需要重写 InventoryManager、HUD、存档、死亡掉落、建造消费 | MVP 不做背包格子；继续使用当前资源字典 |
| 区域硬屏障 | 新增屏障系统成本高，且会让探索变线性 | 改为软门槛：区域压力 + 血清适应 + 氧气窗口 |
| T 键血清面板合并进工作台 | 会重写 UI 和交互；现有 SerumUI 可继续用 | SerumUI 保留，后续再统一 UI |

## 1. MVP 核心体验

### 1.1 一句话玩法

玩家在坠毁地建立临时基地，白天用扫描器和工具深入危险区域采集资源，晚上用建筑防守虫群；通过血清适应更危险的区域，持续供能信号台，最终撑过撤离坚守。

### 1.2 核心循环

```
白天：
  规划目标 → 扫描资源/信号缓存 → 探索采集 → 回基地建造/修理/调制血清/供能信号

夜晚：
  敌人进攻 → 玩家武器 + 炮台 + 慢场 + 护盾协同防守 → 击杀奖励/维修损耗

长期：
  适应区域 → 拿到稀有资源 → 推进信号 25/50/75/100 → 撤离坚守 → 胜利
```

### 1.3 当前保留的 5 个系统

1. **氧气与区域压力**：氧气是探索半径，区域压力改变氧耗/速度/建筑风险。
2. **扫描与采集**：扫描器找可见资源、地下资源、O2 Plant、BP、Signal Cache。
3. **建造与防守**：7 种建筑保留，但引导优先级只突出 Turret、O2 Station、Solar、Research、Signal Beacon。
4. **血清适应**：保留 Lv0-Lv4 适应模型，先修数值和效果，不改成一次性布尔解锁。
5. **信号与撤离**：Signal Beacon 是终局主线，Signal Cache 是探索奖励，Extraction Holdout 是胜利条件。

## 2. 新手期设计（Day 1-3）

### 2.1 开局目标

新手期不新增“飞船零件”系统。用现有 Objective/HUD 引导玩家理解当前核心循环。

| 阶段 | 玩家目标 | 系统目的 |
|------|----------|----------|
| Day 1 白天 | 收集 iron/biomass，建第一座 Turret | 学采集、库存、建造 |
| Day 1 夜晚 | 守住第一波 3-5 只弱敌 | 学战斗与防守 |
| Day 2 白天 | 建 O2 Station 或 Solar Panel | 学续航和能量 |
| Day 2 夜晚 | 修理基地/建筑，理解死亡掉落 | 学维修和风险 |
| Day 3 白天 | 建 Research Station，拿 blueprint，解锁或调制第一个血清 | 进入区域推进 |

### 2.2 不做硬屏障

不做“紫色能量屏障弹回玩家”。原因：

- 需要额外关卡阻挡、碰撞、提示、存档状态。
- 会让探索变成线性钥匙门，削弱氧气窗口带来的风险决策。
- 当前 `ZoneTrigger` 和 `ZoneManager` 已经能表达区域压力。

修订方案：

- 区域入口可直接进入，但 COLD/HEAT/GRAVITY 的压力足够危险。
- HUD 明确提示：`极寒区 | 氧耗 x3.0 | 建议寒域适应 Lv2+`。
- Objective 在玩家第一次进入高压区域后，引导回基地调制对应血清。

## 3. 氧气与区域压力

### 3.1 保留当前氧气框架

- 玩家有 `current_oxygen/max_oxygen`，氧气随时间消耗。
- 开局保留当前 `180s` 设计，不回退到 120s。
- O2 Plant、O2 Kit、O2 Station 都保留。
- 死亡掉落保留，但新手期可降低掉落比例或在 Day 1 第一次死亡豁免。

### 3.2 区域压力采用“软门槛”

现有 `ZoneManager` 已有 Lv0-Lv4 适应等级，不要改成一次性 true/false。

| 区域 | Lv0 压力 | Lv2 后 | Lv4 后 |
|------|----------|--------|--------|
| CRASH | 氧耗 x1.0 | 无变化 | 可给轻微探索奖励 |
| COLD | 氧耗高，探索窗口短 | 氧耗明显降低 | 接近普通氧耗 |
| HEAT | 建筑/前哨有损耗风险 | 结构损耗免疫 | 可提升修理效率 |
| GRAVITY | 移动变慢，返程风险高 | 速度接近正常 | 允许冲刺稳定 |

开发注意：

- `player.gd` 已调用 `ZoneManager.get_oxygen_multiplier()` 和速度相关逻辑，优先修数值与测试。
- `zone_manager.gd` 已有 `get_speed_multiplier()`、`get_structure_drain_rate()`，后续只需要接入结构损耗的执行者。
- 结构损耗不要放在 `build_manager.gd`，应放到 `GameManager` 的结构维护逻辑或结构自身脚本中。

### 3.3 血清设计

保留 SerumUI 与 SerumRecipes，不合并到工作台。

- 每个区域保留 Lv1-Lv4 配方。
- Lv1：降低明显惩罚，让玩家愿意再次进入。
- Lv2：解除主要功能惩罚，例如 HEAT 建筑损耗、GRAVITY 速度惩罚。
- Lv3-Lv4：作为深区效率提升，不作为硬通行证。

验收：

- 进入 COLD 时氧耗明显变快。
- 调制 COLD Lv1/Lv2 后，氧耗倍率下降。
- 进入 GRAVITY 时速度下降，适应后速度恢复。
- HEAT 区建筑损耗只影响该区建筑，适应后停止损耗。

## 4. 扫描、采集与资源刷新

### 4.1 保留扫描器和地下资源

扫描器不是复杂系统，它是当前白天探索的核心：

- `G` 切换目标：iron / biomass / crystal / core / O2 plant / BP。
- 扫描器优先指向地下资源，地下资源需要 Harvester 挖掘。
- 可见资源可直接拾取或用 Harvester 瞄准采集。

### 4.2 每日资源刷新采用保守补给

不要恢复 `GameManager.spawn_resources()` 的基地周围刷资源逻辑。资源补给由 `WorldGenerator` 负责。

MVP 刷新规则：

- 每个白天开始最多生成 **3 个可见资源节点 + 2 个地下资源节点**。
- 只在距离基地 `25m+` 的区域生成。
- 距离已有资源节点优先 `8m+`，如果 30 次尝试失败，允许放宽到 `4m+`。
- 全地图可见资源节点总数设上限，例如 `90`；地下资源总数上限例如 `60`。
- 不要求记录完整玩家足迹，先用“远离基地 + 避开已有节点”即可。

为什么不用“距离玩家 > 40m 且资源 > 15m”：

- 当前地图约 100x100，初始资源已经不少。
- 这个条件容易找不到位置，导致刷新不稳定。
- 简化规则更适合让 GLM 快速实现和测试。

### 4.3 资源经济

不要引入背包格子和基地仓库。当前阶段继续用 `InventoryManager.resources`。

可做的小改：

- HUD 继续显示资源总数。
- 若需要采集压力，后续单独加“死亡掉落/远征风险”，不要先重写库存。
- Blueprint 继续作为研究/解锁资源，不改成随机配方仓库。

## 5. 建造与防守

### 5.1 保留 7 种建筑

上一版 v3 只保留 4 种建筑，但当前 7 种建筑已经接入建造、存档、Objective 和测试。不要删除。

| 建筑 | MVP 定位 |
|------|----------|
| Turret | 基础防守 |
| O2 Station | 扩展探索半径 |
| Shield Generator | 中期基地容错 |
| Solar Panel | 能量来源 |
| Research Station | Blueprint 来源 |
| Slow Field | 防守控制 |
| Signal Beacon | 主线推进与终局入口 |

### 5.2 新手引导只突出核心建筑

为了降低复杂度，Objective 的推荐顺序可以是：

1. Turret
2. O2 Station
3. Solar Panel
4. Research Station
5. Signal Beacon
6. Shield/Slow Field 作为可选强化

### 5.3 结构损耗

HEAT 区结构损耗可以做，但必须满足：

- 只影响 HEAT 区内建筑，不影响基地附近建筑。
- 损耗速度低，例如 `0.1 HP/s` 起步，不要 0.5 HP/s。
- HEAT Lv2 适应后停止损耗。
- HUD/Objective 必须提示“热域建筑正在损耗”，否则玩家会误以为 bug。

## 6. 信号与撤离主线

### 6.1 保留现有主线

不新增“5 个飞船零件”作为代码系统。叙事上可以说 Signal Cache 里包含撤离坐标、飞船校准码、救援协议片段。

现有主线：

```
建 Signal Beacon
→ 消耗 energy 推进信号
→ 25/50/75/100 解锁 Radio Log
→ 生成 Signal Cache
→ 100% 触发 Extraction Holdout
→ 坚守成功即胜利
```

### 6.2 信号数值不要改成 energy/s

当前代码已经改成：

- 每 `12s` 消耗 `1 energy`
- 每次增加 `5%`
- 完成 100% 需要 `20 energy` 和约 `240s`

这个节奏比“1 energy/s”合理得多。GLM 不要改成连续每秒消耗，否则经济表会崩。

### 6.3 撤离坚守

- 当前坚守时间是 `180s`，先保留。
- 读取存档时不要立刻完成撤离；如果读档剩余时间为 0，至少给 UI/信号一帧处理或恢复为极短剩余时间。
- 不新增“Signal Beacon HP 归零直接 Game Over”作为 P0。可以先让敌人攻击普通结构/基地，Signal Beacon HP 作为后续强化。

P0 验收：

- 建 Signal Beacon 后，energy 足够时信号稳定增长。
- 里程碑生成 Radio Log 和 Signal Cache。
- 存档/读档不会多消耗 energy，也不会瞬间胜利。
- 100% 后进入撤离坚守，倒计时结束胜利。

## 7. 传送系统

### 7.1 不砍掉传送

上一版 v3 说砍掉传送，但当前代码已经半接入：

- `TeleportManager` 存在。
- `WorldGenerator` 会注册区域入口。
- `player.gd` 已监听 `teleport` 输入动作。
- `project.godot` 中 teleport 绑定为 `T`。

### 7.2 v3 目标

传送不是主线系统，只作为后期降低跑图疲劳的便利功能。

MVP 规则：

- 保留 `T` 键，不改 `V`。
- 只能白天、只能在基地半径内传送。
- 消耗 `5 energy`，沿用当前代码。
- 目标先使用已注册区域入口，不做复杂传送面板。
- HUD 只需显示简单提示：`T 传送 5 energy`。

后续可扩展：

- Signal Beacon 注册为玩家自建传送点。
- 传送 UI 允许选择目标。
- 夜晚禁止传送或加倍消耗。

- 删除死亡掉落。

这些可以作为 Post-MVP，但不是当前最小可玩闭环。

## 9. GLM 开发切片建议

### P0：修主线稳定性

1. 信号台读档恢复不额外消耗 energy。
2. Extraction 读档不会瞬间胜利。
3. Signal Beacon 进度、Signal Cache、Radio Log 手测通过。
4. 更新 `TEST_PLAN.md` 对应步骤。

### P1：资源补给

1. `WorldGenerator.spawn_daily_resources(day_number)`。
2. 白天开始调用它，但不再调用 `GameManager.spawn_resources()`。
3. 加资源总数上限，避免无限膨胀。
4. 自动测试：Day 2 后资源数量增加但不贴基地刷。

### P2：区域压力补全

1. 调整 `ZoneManager` 数值到可玩范围。
2. 玩家氧耗/速度适应已有接入，补测试。
3. 接入 HEAT 结构损耗，先低数值。
4. HUD 显示当前区域压力与适应等级。

### P3：传送打磨

1. 确认 `T` 键可用。
2. 只允许基地白天传送。
3. 消耗 5 energy。
4. 传送目标使用现有区域入口。

## 10. 手测验收清单

### Day 1-3 新手闭环

1. 新开局能采集 iron/biomass。
2. 能建 Turret 并守住第一夜。
3. 能建 Solar Panel 产生 energy。
4. 能建 Research Station 产生 blueprint。
5. 能建 Signal Beacon 并看到信号进度。

### 区域/血清

1. 进入 COLD 后氧耗明显更快。
2. 调制 COLD 血清后，COLD 氧耗下降。
3. 进入 GRAVITY 后速度下降，适应后速度恢复。
4. HEAT 建筑损耗有 HUD 提示，适应后停止。

### 资源补给

1. 采集一批资源。
2. 进入下一天。
3. 地图远离基地处生成少量新资源。
4. 基地周围不会每天堆满资源。

### 信号/撤离

1. Signal Beacon 每 12 秒消耗 1 energy，增加 5%。
2. 25/50/75/100 里程碑都有 Radio Log。
3. Signal Cache 可被扫描、找到、拾取。
4. 存档/读档后进度、缓存、撤离状态正常。
5. 100% 后进入 180 秒撤离坚守，结束后胜利。
