## 统一视觉与自然交界

紫灰玄武岩保留原月面身份，风化土壤为低饱和灰褐，植被为灰绿至深青绿，河流与近海偏青、外海深蓝。沿用紫色星空与远处环星的身份，但降低地表上的紫光染色；图中不新设计角色、飞船或载具。

1. 岩层沿同一地质方向延续，风化从基岩露头经碎砾、细土到稀草，宽度随坡度和水分变化；绝不用旧六公里所有权方框做艺术边界。
2. 大尺度平原占足够面积，山系集中为脊线、山麓和峡谷；地面景别不把所有生态区压到同一个盆景里。
3. 水流沿低处连接，支流汇入主河，河漫滩在低坡展宽，河口再进入连续海面。芦苇沿浅水岸线形成断续群落，不围每种地貌画一圈。
4. 林缘沿水分、微地形和侵蚀沟自然交错，树群密度逐渐变化，草地空隙伸入林内；不能是棋盘种植或整齐带状换色。
5. 滩地、潮间带、浅海与深海通过地形、水深、悬沙连续过渡；海岸悬崖露出与内陆一致的岩层。
6. 高空减少高频纹理细节，以大尺度岩性、植被和流域读图；轨道看到同一大陆身份与球面，不能出现独立方片或小球盆景。
